## 🐞 Description
When a buyer logs into the BynFor app and opens all messages, the red notification dot on the Message icon continues to appear. This gives a false indication of unread messages, causing confusion and reducing clarity in message notifications.

## 🔁 Steps to Reproduce
1. Go to the BynFor app and log in as a buyer (Account: nikitatesteraccount). 2. Navigate to the Messages section. 3. Open and view all available messages. 4. Return to the main screen and observe the Message icon.


## ❌ Actual Result
The red notification dot remains visible on the Message icon even after all messages have been opened and read.

## ✅ Expected Result
Once all messages are opened, the red notification dot should disappear from the Message icon, indicating there are no unread messages.
