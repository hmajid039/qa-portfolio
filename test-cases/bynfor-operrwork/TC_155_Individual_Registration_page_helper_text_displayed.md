## 🐞 Description
On the Individual Registration page, the helper text displayed below the CAPTCHA input field begins with “NOTE:” in all capital letters, which is inconsistent with the standard sentence casing used across the application.

## 🔁 Steps to Reproduce
1. Navigate to the Registration page. 2. Remians on the individual account type. 3. Scroll down to the CAPTCHA input section. 4. Observe the helper text displayed below the CAPTCHA field.


## ❌ Actual Result
The helper text begins with “NOTE:” written entirely in uppercase letters.

## ✅ Expected Result
The helper text should use proper sentence case, e.g., “Note:” instead of “NOTE:”, to maintain consistent UI text formatting.
