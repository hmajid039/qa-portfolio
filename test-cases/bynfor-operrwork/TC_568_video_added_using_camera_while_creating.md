## 🐞 Description
When a video is added using the camera while creating a real estate listing and the listing is saved as draft, the video behaves inconsistently during playback.

## 🔁 Steps to Reproduce
1. Go to BynFor app and log in (Account: qacomet3) 2. Create a Real Estate listing 3.. Add a video using the camera option 4. Save the listing as Draft 5. Open the draft listing and try to play the video


## ❌ Actual Result
Video thumbnail appears correctly

On play, sometimes the app crashes

Other times, the video plays as a blank screen

## ✅ Expected Result
Draft listing video should play smoothly without crashing or showing a blank screen.
