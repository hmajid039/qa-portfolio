## 🐞 Description
On the View Store page, the “Clear All” option for categories is visible but is not a hyperlink or clickable element. It behaves like plain text, preventing users from clearing selected categories with a single action and impacting usability.

## 🔁 Steps to Reproduce
1. Open the web application on a desktop browser. 2. Log in using a Business or Individual account. 3. Click on the profile icon, then navigate to Selling → Store Information. 4. Fill in all required store information and click Apply and Save. 5. Click on the View store button that appears at the top of the page after saving the store information. 6. Observe the “Clear All” option next to the category filters on the left side of the page. 7. Attempt to click “Clear All”.


## ❌ Actual Result
The “Clear All” text is not clickable and behaves as plain text.

## ✅ Expected Result
The “Clear All” option should be a clickable link or button that clears all selected categories when clicked
