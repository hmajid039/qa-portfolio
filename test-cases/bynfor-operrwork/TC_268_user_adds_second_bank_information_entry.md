## 🐞 Description

However, the newly added bank information card does not appear on the page next to the first saved bank info card. This gives the impression that the new data was not saved or displayed properly.

## 🔁 Steps to Reproduce


## ❌ Actual Result
The system shows a success message but the second bank information card does not appear next to the first one.

## ✅ Expected Result
After saving, the newly added bank information card should appear alongside the existing bank info card.
