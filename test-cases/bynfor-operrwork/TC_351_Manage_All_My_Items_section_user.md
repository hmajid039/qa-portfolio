## 🐞 Description
In the Manage All My Items section, when the user applies the sort dropdown and selects the “End” option, the system incorrectly displays all active listings instead of showing only the listings that are ending. This affects the accuracy of listing management and sorting functionality.

## 🔁 Steps to Reproduce
1. Go to Bynfor and log in (Account Used: qacomet3). 2.Go to listing and Navigate to Manage All My Items. 3. Click on the Sort dropdown. 4. Select the “End” option. 5. Observe the listings displayed.


## ❌ Actual Result
All active listings are displayed regardless of their ending status.

## ✅ Expected Result
Only the listings that are ending soon or marked as ending should be displayed when the “End” sort option is selected.
