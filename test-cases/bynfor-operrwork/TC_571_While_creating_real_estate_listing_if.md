## 🐞 Description
While creating a real estate listing, if the user does not upload any file, the active listing still displays a filename description on the listing, which is incorrect.

## 🔁 Steps to Reproduce
1. Go to BynFor app and log in (Account: qacomet3) 2. Create a Real Estate listing 3. Do not upload any file 4. Submit the listing 5. Open the listing from Active Listings


## ❌ Actual Result
A filename  Des description is shown on the active listing even though no file was uploaded.

## ✅ Expected Result
No filename or file description should be displayed when no file is provided during listing creation.
