## 🐞 Description
The “Email Address 2” field under Real Estate "Use Detailed listing" allows saving invalid email formats without any validation

## 🔁 Steps to Reproduce
1. Log in to Bynfor (majidbusiness / Sun@Ray123) 2. Go to Create a Listing and select Use Detailed Listing tab 3. Select Real Estate and scroll to the field Email Address 2 4. Enter invalid formats e.g: user///@mail, email123@.com etc 5. Observe no validation shown under or after listing


## ❌ Actual Result
Field accepts email without validation and does not show validation or error

## ✅ Expected Result
Field should show an error message like “Please enter a valid email” and not allow non-email formats
