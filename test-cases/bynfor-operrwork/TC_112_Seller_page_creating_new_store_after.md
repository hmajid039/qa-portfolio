## 🐞 Description
On the Seller page, when creating a new store (after selecting “Get a Plan”), there are two “Save & Apply” buttons , one below the store information section and another at the end of the address information section.  Since both sections are required to create a store, the first button’s placement misleads the user into submitting incomplete details. Although an error message appears, it is generic (“Please fill all necessary fields”) and does not specify which section or field is missing.

## 🔁 Steps to Reproduce
1. Log in to the website. 2. Select SELLER CENTER from the sidebar menu. 3. Click on Select a Plan. 4. Observe the presence of two SAVE AND APPLY buttons and try to submit after filling the store information.


## ❌ Actual Result
The presence of two buttons causes confusion and misleads users into believing the form can be submitted in parts.

## ✅ Expected Result
There should be only one “Save & Apply” button at the end of the page after all mandatory fields (including Address Information) are filled.
