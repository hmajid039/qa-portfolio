## 🐞 Description
On the Seller page, within the “Address Information” section, the embedded map appears at the top of the section. This layout causes confusion because users typically expect to fill in the country, state, city, and postal code before viewing the corresponding map preview. The map’s current placement disrupts the logical data-entry flow and may mislead users into thinking they need to interact with the map before entering their address details.

## 🔁 Steps to Reproduce
1. Log in to the website. 2. Select SELLER CENTER from the sidebar menu. 3. Click on Get a Plan. 4.Scroll down to the Address Information section. 5.Observe the position of the map.


## ❌ Actual Result
The map is displayed at the top of the Address Information section, above the input fields.

## ✅ Expected Result
The map should appear below the address input fields  so that users can first enter their information and then view the accurate map location based on the entered details.
