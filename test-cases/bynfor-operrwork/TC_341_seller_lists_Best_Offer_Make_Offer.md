## 🐞 Description
When a seller lists a Best Offer, the “Make an Offer” and “Buy Now” buttons appear disabled. However, clicking on these buttons still performs actions: “Submit an offer” for Make an Offer and navigates to checkout for Buy Now. This misleads users and violates standard UI/UX behavior for disabled buttons.

## 🔁 Steps to Reproduce
1. Go to Bynfor and Log in to the seller account and create a Best Offer listing. 2. Open the listing page as a buyer. 3. Observe that “Make an Offer” and “Buy Now” buttons appear disabled. 4. Click on the buttons.


## ❌ Actual Result
Clicking the disabled buttons still triggers the respective actions: submitting an offer or navigating to checkout

## ✅ Expected Result
Disabled buttons should not be clickable and should not trigger any actions.
