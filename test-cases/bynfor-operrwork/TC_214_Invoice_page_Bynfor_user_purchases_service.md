## 🐞 Description
On the Invoice page in Bynfor, when a user purchases a service that includes additional selected options (e.g., Russian Translator charges, Listing promotion, or Featured ad charges), the generated invoice fails to display all the selected service descriptions. Only partial or general descriptions are shown, leading to incomplete billing details and confusion about what the user was charged for.

## 🔁 Steps to Reproduce
1. Log in to the Bynfor platform. 2. Select a service that includes extra chargeable options (e.g., Russian Translator). 3. Proceed to payment and complete the transaction. 4. Open the Invoice page to view the generated invoice.


## ❌ Actual Result
The invoice only shows a general or incomplete description of charges. Specific services like Russian Translator, Listing promotion, or other selected paid services are missing from the Description of Charges section.

## ✅ Expected Result
The Description of Charges should list all selected and paid services clearly, including each item (e.g., Russian Translator charges, Promotion fee, Ad enhancement, etc.) along with corresponding amounts.
