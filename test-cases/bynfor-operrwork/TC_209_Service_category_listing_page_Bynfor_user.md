## 🐞 Description
On the Service category listing page in Bynfor, when a user clicks on the Available Days dropdown, the list of options overlaps with the fields or boxes below it. This overlap makes it difficult for users to clearly view below part.

## 🔁 Steps to Reproduce
1. Log in to the Bynfor platform. 2. Click on the Profile icon and select Listing. 3. Select the Service category. 4. Scroll to the Available Days field and click on the dropdown. 5. Observe how the dropdown options appear after selction


## ❌ Actual Result
The Available Days dropdown options overlap with the fields below, causing visual clutter

## ✅ Expected Result
The Available Days dropdown should expand clearly without overlapping other input boxes or sections below.
