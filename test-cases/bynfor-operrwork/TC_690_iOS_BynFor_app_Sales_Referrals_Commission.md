## 🐞 Description
In the iOS BynFor app, Sales Referrals Commission listings show the status as Deactivated, but the deactivate timestamp is not displayed in the listing details. The timestamp is available for the same entries in Dev BynFor (web).

## 🔁 Steps to Reproduce
1. Open the BynFor iOS app 2. Log in with a valid account 3. Navigate to Sales Referrals → Commission 4. Open a listing with Deactivated status1


## ❌ Actual Result
The listing shows status as Deactivated, but no deactivate date/time is displayed.

## ✅ Expected Result
The deactivate timestamp should be displayed for deactivated entries, consistent with Dev BynFor.
