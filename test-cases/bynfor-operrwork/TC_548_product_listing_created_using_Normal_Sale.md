## 🐞 Description
A product listing created using the Normal Sale option and saved as Draft shows a “View All Bids” button, which is applicable to Auction/Sealed Bid listings

## 🔁 Steps to Reproduce
1. Open Bynfor android app(majidbusiness / Sun@Ray123) 2. Go to Seller Area →  My Listing → Normal Sale 3. Create a listing using Normal Sale option 4. Save the listing as Draft 5. Open the drafted listing


## ❌ Actual Result
The drafted Normal Sale listing displays a “View All Bids” button and bids: 0

## ✅ Expected Result
“View All Bids” should not appear for Normal Sale listings. Only auction-type listings should show bid-related actions
