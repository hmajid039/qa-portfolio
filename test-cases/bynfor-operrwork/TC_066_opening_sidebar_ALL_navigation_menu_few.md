## 🐞 Description
When opening the sidebar (ALL) navigation menu, a few menu items display tooltips on hover while others don’t. The behavior should be consistent for all options.

## 🔁 Steps to Reproduce
1. Go to the website. 2.Click on the “ALL” button in the top-left corner to open the sidebar menu.   3. Hover the mouse over each option listed in the sidebar.    4. Observe that some items show a tooltip and some do not.


## ❌ Actual Result
Tooltip messages appear only for some sidebar options while others show no tooltip.

## ✅ Expected Result
All sidebar menu options should behave consistently, either all should show tooltips or none should.
