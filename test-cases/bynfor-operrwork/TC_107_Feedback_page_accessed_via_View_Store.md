## 🐞 Description
On the Feedback page accessed via the View Store page, the Positivity Rate displays a default value of 100%. Next to it, there is a “?” icon, which is expected to provide additional information. However, clicking this icon redirects the user to a blank page on bynfor.com, preventing users from accessing the intended information.

## 🔁 Steps to Reproduce
1. Open the web application on a desktop browser. 2. Log in using a Business or Individual account. 3. Click on profile icon and Navigate to Selling → Store Information and click View Store. 4. Click the Feedback button on the View Store page. 5. On the Feedback page, locate the Positivity Rate: 100% field. 6. Click the “?” icon next to the Positivity Rate.


## ❌ Actual Result
1) Positivity rate by default set to 100%                                             2) Clicking the “?” icon redirects to a blank page on bynfor.com.

## ✅ Expected Result
1) The positivity rate should not be the default set                                         2)  Clicking the “?” icon should display a tooltip or page with relevant information about the Positivity Rate without navigating to a blank page.
