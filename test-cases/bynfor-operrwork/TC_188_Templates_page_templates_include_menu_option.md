## 🐞 Description
On the Templates page, for templates that include a menu option (e.g., Men’s store), when opening the Insert Link popup, the checkbox labeled "Open in new window" appears slightly misaligned. In addition, when the checkbox is checked or unchecked, small vertical white boxes briefly appear and the checkbox is also checked/unchecked while clicking on text "Open in new window" .

## 🔁 Steps to Reproduce
1. Loging to website.      2. On the listing page select Settings.    3.Select a template that has a menu option, such as Men’s store. 4.Click the link icon in the text editor to open the Insert Link popup. 5.Observe the checkbox labeled Open in new window while toggling it.


## ❌ Actual Result
1.Checkbox is slightly misaligned with its label.
2.When checked or unchecked, small vertical white boxes appear near the checkbox.
3.Checkbox can be toggled by clicking on both the text and the checkbox itself.

## ✅ Expected Result
1.Checkbox and label should be properly aligned.
2.No extra boxes or visual glitches should appear when toggling.
3.Checkbox interaction should remain smooth without UI distortions.
