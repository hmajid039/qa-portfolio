## 🐞 Description
In the Detailed Service Listing, even when the user selects the Auto List option without entering any day in the respective required fields, the system allows the listing to be submitted successfully without showing any validation errors.

## 🔁 Steps to Reproduce
1. Go to Bynfor and log in (Account Used: qacomet3). 2.Create a new Detailed Service Listing. 3. Select the Auto List option. 4. Leave the days field empty. 5. Attempt to submit/list the service. 6. Observe whether the system shows any validation errors.


## ❌ Actual Result
The system allows the listing to be submitted successfully without entering any days and without showing validation errors.

## ✅ Expected Result
The system should prevent listing and display a validation error indicating that the days field is required.
