## 🐞 Description
Auction Event , Seller Info ,  View Store, when a user clicks on a store box, it becomes selected (indicated by a color change). However, clicking on another store box causes both the newly clicked box and previously selected boxes to remain selected simultaneously. This leads to multiple boxes being selected at once, causing UI inconsistency and user confusion.

## 🔁 Steps to Reproduce
1. Open the Bynfor website  (majidbusiness / Sun@Ray123). 2. Navigate to Auction Event ,Seller Info ,View Store 3. Click on a store box and observe it becomes selected 4. Click on another store box


## ❌ Actual Result
Multiple store boxes remain selected simultaneously after clicking different boxes, instead of only one being selected at a time.

## ✅ Expected Result
Selecting a new store box should automatically deselect any previously selected box, ensuring that only one box is selected at any given time.
