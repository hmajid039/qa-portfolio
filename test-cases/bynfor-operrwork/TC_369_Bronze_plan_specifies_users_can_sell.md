## 🐞 Description
The Bronze plan specifies that users can sell a maximum of 2 products. However, users are currently able to list and sell more than 2 products without receiving any restriction or upgrade prompt. This violates the plan’s defined sale limit and can result in revenue loss.

## 🔁 Steps to Reproduce
1. Go to Bynfor and Log in and activate the Bronze plan. 2. List and sell the 1st product. 2. List and sell the 2nd product. 3. Attempt to list and sell the 3rd product.


## ❌ Actual Result
The user is able to list and sell more than 2 products without any restrictions.

## ✅ Expected Result
The system should prevent the user from selling more than 2 products, and display a prompt to upgrade the plan.
