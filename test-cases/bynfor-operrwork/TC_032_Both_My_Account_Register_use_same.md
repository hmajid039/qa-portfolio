## 🐞 Description
Both “My Account” and “Register” use the same icon. On Android devices, these icons are displayed on the same line in the header, which looks confusing and visually awkward. On desktop web, the icons are placed in separate sections of the header, so the same-icon issue is not noticeable and the layout looks clean. The combination of identical icons on the same line on Android creates a UI inconsistency.

## 🔁 Steps to Reproduce
1. Open the application on an Android device. 2. Navigate to the header section. 3. Observe the placement of the “My Account” and “Register” icons. 4. Compare with the desktop web header layout.


## ❌ Actual Result
On Android, both icons appear on the same line in the header and look confusing because they are identical.

## ✅ Expected Result
Icons should be visually distinguishable or repositioned to avoid confusion, maintaining clarity similar to the desktop layout.
