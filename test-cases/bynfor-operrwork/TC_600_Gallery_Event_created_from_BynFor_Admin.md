## 🐞 Description
When a Gallery Event is created from the BynFor Admin panel with a Privacy Policy URL, the link appears as plain text on the dev BynFor Gallery Event listing instead of being clickable.

## 🔁 Steps to Reproduce
1. Go to BynFor Admin panel and log in 2. Navigate to Gallery Events 3. Create a Gallery Event and add a valid URL under Privacy Policy 4. Save the event 5. Open the Gallery Event listing on dev BynFor


## ❌ Actual Result
The Privacy Policy URL is displayed as non-clickable plain text.

## ✅ Expected Result
The Privacy Policy URL should be rendered as a clickable link and open the linked page when clicked.
