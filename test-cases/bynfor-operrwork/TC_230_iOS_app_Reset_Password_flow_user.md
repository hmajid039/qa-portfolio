## 🐞 Description
In the iOS app Reset Password flow, when the user selects Phone as the recovery option, the phone number input field is completely missing

## 🔁 Steps to Reproduce
1. Open the iOS app. 2. Go to Login page. 3. Tap Forgot Username/Password → select Forgot Password. 4. Choose Phone as the recovery method. 5. Observe that the phone number field does not appear.


## ❌ Actual Result
The phone number input field is missing, preventing the user from proceeding with password reset via phone.

## ✅ Expected Result
A phone number input field (with country code selector) should appear when the user selects Phone as the reset method, allowing entry of a valid phone number to receive a verification code.
