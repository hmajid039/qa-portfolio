## 🐞 Description
When the user clicks on the Register button from the home page, the Sign In popup appears instead. The user then has to manually switch to the Register tab inside the popup. This causes unnecessary extra steps and is not aligned with expected user behavior.

## 🔁 Steps to Reproduce
1. Go to "https://dev.bynfor.com/home"       2.Click the Register button on the home page header 3.Observe the popup that appears


## ❌ Actual Result
The Sign In popup appears, and the user must manually click the Register button on the popup to access the registration form.

## ✅ Expected Result
Clicking Register on the home page should directly open the Register popup by default.
