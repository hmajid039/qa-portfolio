## 🐞 Description
On the Create Listing page under the Listing Format section, each option such as Sale, Sealed Bid, Reverse Bid, etc., displays duplicate radio buttons beside each option.

## 🔁 Steps to Reproduce
1. Go to the Bynfor web application and log in. 2. Navigate to Profile → Listing → Create Listing. 3. Observe the  Listing Format section.  .


## ❌ Actual Result
Each listing format option shows two radio buttons — one functional and one unnecessary duplicate.

## ✅ Expected Result
Each listing format option should have only one radio button for selection. The extra duplicate radio buttons should be removed.
