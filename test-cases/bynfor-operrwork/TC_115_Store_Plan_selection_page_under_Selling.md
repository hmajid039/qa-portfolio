## 🐞 Description

 , Final Fee Value for Auction15%
 ,Final Fee Value for Others etc) are not clickable.

1. Go to the Bynfor web application and log in. 2. Click on the Profile icon and navigate to the Selling section. 3. Try clicking on any links under the plans (e.g., “Learn More” or “View Details”).

The links under each plan are not clickable — there is no navigation or response upon clicking.

Each link under the plans should be clickable and should redirect users to the corresponding detailed plan information or relevant page.
