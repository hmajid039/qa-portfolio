## 🐞 Description
On the View Store page, the section titled “Filter” does not have any functional filters. Users are unable to apply any filtering criteria, which limits the usability and navigation of the page.

## 🔁 Steps to Reproduce
1. Open the web application on a desktop browser. 2. Log in using a Business or Individual account. 3. Navigate to Selling → Store Information and ensure a store is set up. 4. Click the View Store button. 5. Observe the section titled “Filter” on the page.


## ❌ Actual Result
The “Filter” section is present, but no filter functionalities are available.

## ✅ Expected Result
Users should be able to apply filtering options under the “Filter” section to refine the displayed items in the View Store page.
