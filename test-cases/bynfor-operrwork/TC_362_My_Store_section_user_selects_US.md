## 🐞 Description
In the My Store section, when the user selects a US phone number with country code (+1), the OTP Verification option is visible. However, when the user selects any other country code, the OTP Verify option disappears, preventing the user from verifying phone numbers of other countries. This results in only US-based phone numbers being verifiable.

## 🔁 Steps to Reproduce
1. Go to BynFor and Go to My Store from MyProfile icon>Selling. 2. Click on the Phone Number field. 3. Select United States (+1) country code and observe that the OTP Verify option is shown. 4. Change the country code to any other country (e.g., India +91, UK +44, etc.). 5. Observe the OTP Verify option.


## ❌ Actual Result
The OTP verification option is only visible for US numbers, and disappears for all other country codes, making non-US numbers unverifiable.

## ✅ Expected Result
The OTP Verification option should appear for all valid country codes, not only for US-based numbers.
