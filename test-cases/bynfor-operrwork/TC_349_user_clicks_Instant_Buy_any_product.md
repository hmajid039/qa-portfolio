## 🐞 Description
When the user clicks Instant Buy on any product, the displayed price initially shows 0 and then updates to the correct price after a brief moment. This may confuse users and affect the perceived reliability of the platform

## 🔁 Steps to Reproduce
1. Go to Bynfor and log in (Account Used: qacomet3). 2. Navigate to any product available for Instant Buy. 3. Click on Instant Buy. 4. Observe the price displayed before it updates to the correct value.


## ❌ Actual Result
The price initially shows 0, then updates to the correct value after a brief delay.

## ✅ Expected Result
,The correct price should display immediately without showing 0 at any point.
