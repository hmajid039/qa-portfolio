## 🐞 Description
When a user creates a listing under Advertisement, the input fields for Phone Number and Email contain unnecessarily long placeholder text. The placeholders currently show “enter contact phone number” and “enter contact email”, which is redundant

## 🔁 Steps to Reproduce
1.Go to BynFor web. 2. Log in with a valid user account. 3. Click on the Profile icon and select Listing. 4. Click on Create a Listing. 5.Select Advertisement and choose a Category. 6. Observe the Phone Number and Email text boxes.


## ❌ Actual Result
Placeholders display “enter contact phone number” and “enter contact email” inside the input boxes.

## ✅ Expected Result
Placeholders should be minimal and concise: “Enter phone number” and “Enter email”.
