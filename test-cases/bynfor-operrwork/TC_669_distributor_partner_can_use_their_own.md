## 🐞 Description
A distributor partner can use their own sharing link to purchase a product and incorrectly receive commission.

## 🔁 Steps to Reproduce
1. Log in as distributor partner in dev Bynfor(qacomet3) 2. Generate sharing link 3. Open the same link and purchase the product 4. Check wallet/commission


## ❌ Actual Result
Distributor earns commission on self-purchase.

## ✅ Expected Result
Self-purchases using own sharing link should be blocked from earning commission.
