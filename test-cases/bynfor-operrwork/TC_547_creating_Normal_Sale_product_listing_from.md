## 🐞 Description
When creating a Normal Sale product listing from the mobile app and saving it as Draft, the uploaded product image is not displayed. Instead, the default Bynfor logo image appears

## 🔁 Steps to Reproduce
1. Open Bynfor android app(majidbusiness / Sun@Ray123) 2. Go to Seller Area →  My Listing → Normal Sale 3. Upload a product image 4. Save the listing as Draft 5. Go to Draft Listings and view the saved draft


## ❌ Actual Result
The drafted listing from android app shows the default Bynfor logo image instead of the uploaded product image

## ✅ Expected Result
The drafted listing should display the actual uploaded product image, even in Draft state
