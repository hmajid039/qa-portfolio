## 🐞 Description
When a user clicks Credit/Debit Card on the Payment Options page, a Select Card popup appears. The popup correctly shows the card details, but under the card heading, the label “Add to Cart” is displayed which is misleading

## 🔁 Steps to Reproduce
1. Open the Bynfor app android(appuser / Sun@Ray123) 2. Navigate to Marketplace -> Instant Buy 3. Add a product to the cart 4. Open the cart 5. Go to Payment Options page during checkout 6. Click Credit/Debit Card to select a card for payment 7. Check the label under the card: it incorrectly shows “Add to Cart”.


## ❌ Actual Result
Select Card popup displays “Add to Cart” under the card details

## ✅ Expected Result
The label under the card should indicate “Select Card”, “Pay with this card”
