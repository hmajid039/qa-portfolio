## 🐞 Description
On the Fine Art Listing creation page, the External Link input field does not retain user input. When a user types any character, it gets automatically erased, preventing entry of a valid link.

## 🔁 Steps to Reproduce
1. Go to BynFor app and log in (Account: qacomet3) 2. Navigate to Create Listing → Fine Art 3. Locate the External Link textbox 4. Try typing any URL or text in the field


## ❌ Actual Result
Typed characters are auto-erased immediately and the textbox remains empty.

## ✅ Expected Result
The External Link textbox should allow users to type and retain the entered text/URL.
