## 🐞 Description
When a Seller rejects a Distributor Partner request, selecting Rejected Application from the Status dropdown does not display any records, even though a rejected application exists.

## 🔁 Steps to Reproduce
1. Go to BynFor app and log in as Seller account(qacomet3) 2. Navigate to Partnership Programme 3. Reject a Distributor Partner request 4. Open the Status dropdown 5. Select Rejected Application


## ❌ Actual Result
No data is shown; the list appears blank.

## ✅ Expected Result
Rejected distributor partner applications should be displayed when Rejected Application is selected.
