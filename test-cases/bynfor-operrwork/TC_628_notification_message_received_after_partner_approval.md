## 🐞 Description
The notification message received after partner approval contains unclear and incorrect text, making it difficult for users to understand the action performed

## 🔁 Steps to Reproduce
1. Log in to the Bynfor dev website 2. Navigate to Partnership Programs → Distributor Partnership 3. Fill the fields and Click Submit for Review 4. Approve the request from business account 5. Observe notification received on distributor account


## ❌ Actual Result
Notification text: “Admin you as become partner with the name has approved you as become partner with the registered name userpartner”

## ✅ Expected Result
A clear and readable message, for example:
“Your partner application has been approved by Admin for the registered name: userpartner.”
