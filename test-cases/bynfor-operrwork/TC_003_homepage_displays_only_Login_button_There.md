## 🐞 Description
The homepage displays only a “Login” button. There is no visible “Register” or “Sign Up” button for new users, which can confuse first-time visitors who want to create an account.

## 🔁 Steps to Reproduce
1. Open the Bynfor homepage (https://bynfor.com/) 2. Observe the header or main navigation area 3. Only the Login button is visible; no option to register


## ❌ Actual Result
The homepage only shows the Login button. No visible Register button is provided.

## ✅ Expected Result
Both Login and Register buttons should be visible on the homepage so that new users can easily sign up.
