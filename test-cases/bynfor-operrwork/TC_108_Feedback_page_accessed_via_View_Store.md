## 🐞 Description
On the Feedback page accessed via the View Store page, the store logo is not visible.

## 🔁 Steps to Reproduce
1. Open the web application on a desktop browser. 2. Log in using a Business or Individual account. 3. Navigate to Selling → Store Information and ensure the store has a logo uploaded. 4. Click the View Store button. 5. Click on the Feedback button to open the Feedback page. 6. Observe the presence or absence of the store logo on this page.


## ❌ Actual Result
The store logo is not displayed on the Feedback page.

## ✅ Expected Result
The store logo should be visible on the Feedback page, consistent with the branding shown on other store-related pages.
