## 🐞 Description
On the Distributor Partnership page, the filter dropdown for application status includes “Application Status” as a selectable filter option instead of acting only as a label or placeholder. This can confuse users, as it is not a valid status value

## 🔁 Steps to Reproduce
1. Log in to the Bynfor dev website(majidbusiness / Sun@Ray123) 2. Click on the avatar located in the top right corner 3. Navigate to Partnerrship programs 4. Locate the Application Status filter dropdown 5. Click on the dropdown 6. Observe that “Application Status” appears as a selectable option


## ❌ Actual Result
“Application Status” is displayed and selectable as an option in the filter dropdown

## ✅ Expected Result
Application Status” should act only as a label or placeholder and should not be selectable as a filter option. Only valid status values (e.g., Waiting Approve/Reject, Approved) should be selectable
To allow viewing all applications, a clearly labeled option such as “All Applications” or “All Statuses” should be provided instead
