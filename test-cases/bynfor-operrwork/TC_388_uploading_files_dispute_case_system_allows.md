## 🐞 Description
When uploading files in a dispute case, the system allows the user to upload a file with the same name repeatedly. No error or warning message (e.g., “A file with this name already exists”) is displayed.

## 🔁 Steps to Reproduce
1. Log in as Business(majidbusiness/Sun@Ray123) 2. Navigate to Dispute Center 3. Open any dispute → Click the view icon to view details. 4. Add a message and upload a file with same name multiple times 5.Click on submit button. 6. Observe the behavior.


## ❌ Actual Result
The application allows uploading the same file name multiple times without showing any error.

## ✅ Expected Result
The system should prevent duplicate file uploads and display an error such as:
“A file with the same name already exists.”
