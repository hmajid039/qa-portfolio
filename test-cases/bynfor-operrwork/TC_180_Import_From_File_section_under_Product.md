## 🐞 Description
In the “Import From File” section under Product Listing, the “Bulk Template Type” field shows an  up–down icon instead of the standard dropdown arrow icon.

## 🔁 Steps to Reproduce
1.Go to the Seller Center from sidebar menu.                                 2. Select List an item. 3.Scroll down to the Import From File Section. 4. ObserveThe Bulk Template Type field icon for "Use Simple Listing", "Use Detailed Listing" and "Advertisements".


## ❌ Actual Result
The Bulk Template Type field shows an up-down icon instead of a dropdown arrow icon.

## ✅ Expected Result
The “Bulk Template Type” field should show a dropdown arrow (▼) to indicate that it’s a dropdown selection field.
