## 🐞 Description
On the Store Layout page, when clicking anywhere near the label (e.g., Category 1 (Add content and upload image)), the content upload panel opens unintentionally. The panel should only open when the user specifically clicks on the label text itself, not when clicking on the surrounding empty space or nearby area.

## 🔁 Steps to Reproduce
1. Loging to website.      2. On the listing page select Settings.    3.Select a template that has a menu option, such as Men’s store.    4.Locate a label such as Category 1 (Add content and upload image). 5.Click anywhere near or beside the label (not directly on it).


## ❌ Actual Result
The content upload panel opens even when clicking in the empty space next to the label.

## ✅ Expected Result
The content upload panel should only open when the user clicks directly on the label text.
