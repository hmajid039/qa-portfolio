## 🐞 Description
On the listing page when Best Offer is selected for Sales Format, the checkbox under the Product Specifics “Do you want to list this as a fine arts product?” can be selected or deselected not only by clicking inside the checkbox but also when clicking on the text label or the white space below it. The expected behavior is that the checkbox should toggle only when clicked directly inside the checkbox area.

## 🔁 Steps to Reproduce
1. Go to Listing page → Create Simple Listing and select Best offer for Sales Format .  2.Locate the checkbox “Do you want to list this as a fine arts product?” under Product Specifies.  3. Try clicking on the text label, below the checkbox, and inside it.


## ❌ Actual Result
The checkbox can be toggled when clicking on the text label, below the checkbox, and inside the checkbox.

## ✅ Expected Result
The checkbox should only toggle when clicked directly inside the checkbox area.
