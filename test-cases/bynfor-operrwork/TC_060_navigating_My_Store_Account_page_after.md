## 🐞 Description
When navigating to the My Store Account page after clicking Choose a Plan on the Seller side, the country code and phone number input fields overlap. The first 3–4 digits of the phone number are not visible.

## 🔁 Steps to Reproduce
1. Go to the website.   2. Choose Seller Center from left side of menu. 3. select Choose a plan. 4Observe the My Store Account page where country code and phone number fields appear.


## ❌ Actual Result
Country code and phone number fields overlap, hiding the first few digits of the phone number.

## ✅ Expected Result
Country code and phone number fields should be clearly separated with proper spacing, ensuring all digits are visible.
