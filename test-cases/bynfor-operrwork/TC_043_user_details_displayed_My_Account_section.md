## 🐞 Description
.The user details displayed in the My Account section and on Social Media integrations are not being translated into the selected language. This leads to inconsistent localization and a confusing user experience.

## 🔁 Steps to Reproduce
1. Log in to the application. 2. Navigate to the My Account section. 3. Observe the user details displayed. 4. Navigate to any connected Social Media sections and check user details.


## ❌ Actual Result
User details are displayed in the default language and are not translated according to the selected language.

## ✅ Expected Result
User details in My Account and Social Media sections should reflect the selected language consistently.
