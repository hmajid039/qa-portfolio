## 🐞 Description
When a user selects the Real Estate category while creating a new listing, a popup titled “Choose how you want to list your Real Estate” appears with three package options. The first option, which is “30 Days Trial”, does not display a radio button for selection, unlike the other two options

## 🔁 Steps to Reproduce
1. Go to BynFor, log in, and click on the My Account icon. 2. Navigate to Listing → Create a Listing. 3. Select Real Estate as the category. 4. Observe the popup “Choose how you want to list your Real Estate” with three package options. 5. Check the first option (30 Days Trial) — the radio button is missing.


## ❌ Actual Result
The “30 Days Trial” option is displayed without a radio button, making it unselectable.

## ✅ Expected Result
All package options, including the “30 Days Trial”, should have visible and functional radio buttons allowing users to make a selection.
