## 🐞 Description
When the user creates a new service listing, the phone number field is automatically displayed as “Verified” even though the user has not entered any phone number. This can mislead users and may cause incorrect contact details to be associated with the listing.

## 🔁 Steps to Reproduce
1. Go to the Bynfor and log in(Account used:qacomet3) 2. Navigate to Create Service Listing. 3. Scroll to the Phone Number section. 4. Observe the status of the phone number field before entering any value.


## ❌ Actual Result
The phone number field is already displayed as Verified, even when the user has not entered any phone number.

## ✅ Expected Result
The phone number field should remain unverified until the user enters a valid phone number and completes the verification process
