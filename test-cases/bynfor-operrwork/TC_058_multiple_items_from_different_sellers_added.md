## 🐞 Description
When multiple items from different sellers are added to the cart, there is no checkbox or selection mechanism to choose only specific items for checkout. Currently, users can only remove (discard) items they do not wish to purchase.

## 🔁 Steps to Reproduce
1. Add multiple items from different sellers to the cart. 2.Go to the Shopping Cart page. 3.observe there's no such option.


## ❌ Actual Result
There is no checkbox or selection feature to choose specific items for checkout, the only available action is to remove an item.

## ✅ Expected Result
Users should be able to select which items they want to proceed with for checkout while keeping the rest in the cart.
