## 🐞 Description
When attempting to log in using an invalid username, the app displays an incorrect error message stating “Sorry, for security purposes you've been blocked out Bynfor. For any questions regarding your account please visit our help centter.” This message is misleading since the user has not been blocked but is simply entering invalid credentials.

## 🔁 Steps to Reproduce
1. Open the Bynfor app on android.         2 Navigate to the Login page. 3. Enter an invalid username 4.Tap on the “Login” button.


## ❌ Actual Result
The app displays a misleading message implying the user has been blocked for security purposes.

## ✅ Expected Result
A clear error message should appear such as “Invalid username or password. Please try again.”
