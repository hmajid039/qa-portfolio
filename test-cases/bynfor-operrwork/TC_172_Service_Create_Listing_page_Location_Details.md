## 🐞 Description
On the Service Create Listing page, the Location Details section appears as a large, blank box that is non-fillable.

## 🔁 Steps to Reproduce
1. Go to the Bynfor web application and log in. 2. Navigate to Profile → Listing → Create Listing → Select category as Service. 3. Scroll to the Location Details section.


## ❌ Actual Result
The Location Details box is visible but cannot be filled. It looks like a large, empty container with no input functionality.

## ✅ Expected Result
The Location Details section should provide fillable input fields for users to enter the relevant location information (address, city, state, postal code, etc.).
