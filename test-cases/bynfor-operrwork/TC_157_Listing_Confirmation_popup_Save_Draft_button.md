## 🐞 Description
On the Listing Confirmation popup, the “Save Draft” button is not properly aligned within the popup boundary. It partially extends outside the popup box, causing a layout issue and making the UI look unpolished and inconsistent.

## 🔁 Steps to Reproduce
1.Go to the Bynfor web application and log in. 2. Click on the Profile icon and navigate to Listing → Create Listing. 3. Fill out the listing details and proceed to Save Draft. 4. Observe the confirmation popup that appears before saving the draft.


## ❌ Actual Result
The “Save Draft” button is misaligned and appears partially outside the confirmation popup.

## ✅ Expected Result
The “Save Draft” button should be fully visible and properly aligned within the popup boundary.
