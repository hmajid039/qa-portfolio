## 🐞 Description
On the View Store page, the action buttons such as Message, Follow, Subscribe, Favorite, and Friends are non-functional. Clicking on these buttons does not trigger any action, preventing users from interacting with the store as intended.

## 🔁 Steps to Reproduce
1. Open the web application on a desktop browser. 2. Log in using a Business or Individual account. 3. Navigate to Selling → Store Information and ensure a store is set up. 4. Click the View Store button. 5. Attempt to click on any of the action buttons: Message, Follow, Subscribe, Favorite, Friends.


## ❌ Actual Result
The buttons do not respond when clicked and perform no action.

## ✅ Expected Result
Each button should be fully functional, triggering its intended action:

Message: Open messaging window

Follow: Follow the store/user

Subscribe: Subscribe to store updates

Favorite: Add store to favorites

Friends: Send a friend request or open friends list
