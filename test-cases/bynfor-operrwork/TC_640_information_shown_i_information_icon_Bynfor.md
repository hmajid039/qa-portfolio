## 🐞 Description
The information shown in the “i” (information) icon for Bynfor Partnership Programs states that users can sign up to be a distributor for multiple stores. However, after a partner application is approved, the “Become Sales or Merchant Partner” page continues to display the application form for the approved store only. There is no clear indication or action to apply for another store, which can confuse users and makes the new application flow unclear

## 🔁 Steps to Reproduce
1. Log in to the Bynfor website 2. Navigate to Partnership Programs → Become Sales or Merchant Partner 3. Submit an application for a store 4. Approve the application from the store owner account 5. Revisit the Become Sales or Merchant Partner tab


## ❌ Actual Result
Approved application form is still displayed
No clear option or button to apply for another store

## ✅ Expected Result
Clear indication that the user is already approved for the selected store
A visible option such as:
“Apply for another store”
Better separation between approved partner details and the new application flow, in line with the information shown in the “i” icon
