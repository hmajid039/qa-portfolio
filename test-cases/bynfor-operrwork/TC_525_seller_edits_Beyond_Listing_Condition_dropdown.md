## 🐞 Description
When the seller edits a Beyond Listing, the Condition dropdown becomes empty even though the value was correctly selected during the original listing creation. The field does not retain previously saved data.

## 🔁 Steps to Reproduce
1. Go to BynFor and log in (Account: qacomet3) 2. Create a Beyond Listing 3. Select any value in the Condition dropdown 4. Submit the listing 5. Open the Active Beyond Listing and click Edit 6. Check the Condition dropdown field


## ❌ Actual Result
The Condition dropdown appears blank during edit mode, losing the previously selected value.

## ✅ Expected Result
Condition dropdown should retain and display the saved selection when editing the listing.
