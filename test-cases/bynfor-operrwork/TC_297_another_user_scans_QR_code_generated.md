## 🐞 Description
When another user scans the QR code generated under My Account, it fails to open the intended profile or item and instead displays an “Item not found” error. This issue affects the QR sharing functionality and prevents users from accessing shared content.

## 🔁 Steps to Reproduce
1. Go to BynFor app and log in (Account: qacomet2) 2. Navigate to My Account and generate or view the QR code 3. Log in with another account on a different device 4. Scan the QR code from the first account


## ❌ Actual Result
The system displays an “Item not found” error after scanning the QR code.

## ✅ Expected Result
The QR code should correctly redirect other users to the corresponding profile or item without any errors.
