## 🐞 Description
When logged in with a Personal Account, clicking the “List an Item” button on the Seller page incorrectly redirects the user to the Home page instead of opening the Listing page where items should be added.

## 🔁 Steps to Reproduce
1.Log in using a Personal Account. 2.Navigate to the Seller page. 3.Click the “List an Item” button.


## ❌ Actual Result
User is redirected to the Home page instead.

## ✅ Expected Result
User should be redirected to the Listing page to add or manage items.
