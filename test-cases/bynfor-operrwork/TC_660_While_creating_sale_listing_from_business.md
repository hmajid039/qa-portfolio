## 🐞 Description
While creating a sale listing from a business account, (majidbusiness / Sun@Ray123) the shipping service options allow multiple selections at the same time. Selecting one shipping option does not deselect the previously selected option, allowing all shipping methods to remain selected together.

## 🔁 Steps to Reproduce
1. Log in using a business account. 2. Create a new sale listing. 3. Navigate to the Shipping Services section. 4. Select Free Shipping. 5. Select Flat Rate Shipping or USPS Shipping.


## ❌ Actual Result
The system allows multiple shipping options (Free Shipping, USPS Shipping, Flat Rate Shipping) to be selected at the same time.

## ✅ Expected Result
Only one shipping option should be selectable at a time. Selecting a new shipping option should automatically deselect the previously selected option.
