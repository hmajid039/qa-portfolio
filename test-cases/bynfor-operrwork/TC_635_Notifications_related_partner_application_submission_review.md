## 🐞 Description
Notifications related to partner application submission, review, or approval are automatically marked as read without user interaction. This behavior is inconsistent with other notification types (e.g., friend requests), which remain unread until explicitly opened, even after the related action is completed

## 🔁 Steps to Reproduce
1. Log in to the Bynfor dev website 2. Receive a partner-related notification (submission/review/approval) 3. Do not click the notification 4. Navigate to the related partner page 5. Observe the notification is marked as Read 6. Compare with a friend request notification behavior


## ❌ Actual Result
Partner-related notifications are marked as Read automatically without being clicked

## ✅ Expected Result
Notification read behavior should be consistent across all notification types and should remain Unread until the user explicitly opens the notification
