## 🐞 Description
While creating a listing, selecting Fixed commission type for Level 1 prevents the listing from being created. No error message is shown. The same listing works correctly when Percentage commission type is selected. This indicates a possible issue with Fixed commission handling

## 🔁 Steps to Reproduce
1. Log in as a store owner 2. Navigate to create a new listing 3. Fill all required listing details 4. Click “Commission Setup” 5. Select Level 1 6. Select commission type as Fixed 7. Enter a valid fixed commission amount 8. Click Confirm 9. Click List Item


## ❌ Actual Result
Listing is not created

No error or validation message is shown

## ✅ Expected Result
Listing should be created successfully when Fixed commission is selected

Or a clear error message should be shown if something is wrong
