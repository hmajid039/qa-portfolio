## 🐞 Description
While submitting the Distributor Partner request, the Referral field is marked as mandatory (red *). However, leaving it empty and clicking the “Submit for Review” button successfully submits the form. This should not be allowed

## 🔁 Steps to Reproduce
1. Log in to the Bynfor dev website ( majidB / Sun@Ray123) 2. Navigate to Partnership programs → Distributor Partnership → Become Store's Partner 3. Leave the Referral field empty 4. Fill other mandatory fields 5. Click Submit for Review 6. Observe that the form is submitted successfully even though the Referral field is empty


## ❌ Actual Result
Form submits successfully without entering Referral

## ✅ Expected Result
Form should not submit and should show an error message prompting the user to enter a valid Referral
