## 🐞 Description
When a user searches for “sign up” in the Help Center search box the search results correctly display relevant articles for “Sign Up.” However, a “Not Found” message appears just below the search box, giving a misleading impression that no results exist

## 🔁 Steps to Reproduce
1. Login to dev bynfor(user888/user123) 2. Navigate to the Help Center 3. Enter “sign up” in the search box and press Enter 4. Observe the search results displayed 5. Notice the “Not Found” tab/message appearing below the search bar


## ❌ Actual Result
Relevant search results appear, but the “Not Found” message is also displayed, causing confusion

## ✅ Expected Result
Only relevant search results should be displayed. The “Not Found” message should not appear when results exist
