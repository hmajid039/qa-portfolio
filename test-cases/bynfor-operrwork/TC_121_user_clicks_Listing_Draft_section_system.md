## 🐞 Description
When a user clicks on the Listing Draft section, the system initially displays a message saying “No matching found” even though drafts exist. After a brief delay, the actual listings appear.

## 🔁 Steps to Reproduce
1. Go to the Bynfor web application and log in. 2. Navigate to the Selling section. 3. Click on Listing Draft. 4. Observe the initial message and the subsequent display of listings.


## ❌ Actual Result
The message “No matching found” appears briefly before the draft listings are displayed.

## ✅ Expected Result
The draft listings should load immediately without showing an incorrect “No matching found” message.
