## 🐞 Description
When a user selects the Real Estate category while creating a new listing, a popup appears titled “Choose how you want to list your Real Estate” with three package options. The second option, which is “$100 annual package deal with verification of 12 listings,” has an incorrect tooltip that mentions “for any user who select $12 annual package…” instead of referring to the $100 package. This creates confusion about pricing and package benefits.

## 🔁 Steps to Reproduce
1. Go to BynFor, log in, and click on the My Account icon. 2. Navigate to Listing → Create a Listing. 3. Select Real Estate as the category. 4. Observe the pop-up “Choose how you want to list your Real Estate” that appears with 3 options. 5. Hover over the tooltip of the second option ($100 annual package deal with verification of 12 listings)


## ❌ Actual Result
The tooltip incorrectly shows the message:
“for any user who select $12 annual package will get…”

## ✅ Expected Result
The tooltip should correctly refer to the $100 annual package, e.g.,
“for any user who selects the $100 annual package will get verification for 12 listings.”
