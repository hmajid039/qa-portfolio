## 🐞 Description
On the payment options page, the shipping address input fields display an “X” icon (used for clearing text). However, the “X” icon does not disappear even after valid input is entered in the fields. This creates a cluttered UI and may confuse users by implying that the input is invalid or incomplete.

## 🔁 Steps to Reproduce
1. Go to BynFor app and log In (Account:qacomet3)                                      2. Navigate to the Payment Options page. 3. Go to the Shipping Address section. 4. Observe the “X” icon present under each address input field. 5. Fill in all required address details (e.g., Name, City, Postal Code, Address, etc.).


## ❌ Actual Result
The “X” icon under the address fields remains visible even after the fields are filled.

## ✅ Expected Result
The “X” icon should no present on Shipping fields.
