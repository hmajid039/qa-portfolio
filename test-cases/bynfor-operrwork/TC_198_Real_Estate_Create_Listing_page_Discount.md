## 🐞 Description
On the Real Estate Create Listing page, the Discount button remains disabled even when the user fills in valid values for Rent and Security Deposit fields. This prevents users from applying discounts to their listing and impacts the functionality of pricing options.

## 🔁 Steps to Reproduce
1. Go to BynFor, log in, and click on the My Account icon. 2. Navigate to Listing → Create a Listing. 3. Select Real Estate as the category. 4. Fill in valid amounts in the Rent and Security Deposit fields. 5. Observe the Discount text box disabled..


## ❌ Actual Result
The Discount button remains disabled even after entering amounts in Rent and Security Deposit fields.

## ✅ Expected Result
The Discount button should be enabled once valid values are entered in Rent and Security Deposit fields, allowing users to apply discounts.
