## 🐞 Description
When a user creates and saves a new Real Estate listing, a confirmation popup appears with the message:
“Please be sure that the information you have provided for this listing is as accurate as possible to avoid any problems down the line. You can only revoke and update the listing within 0 minutes. Are you sure you have the item and it is what you described?”
The “0 minutes” value is incorrect and should display the actual duration allowed for editing or revoking the listing.

## 🔁 Steps to Reproduce
1. Go to BynFor, log in, and click on the My Account icon. 2. Navigate to Listing → Create a Listing. 3. Select Real Estate as the category and fill in all required information. 4. Click Save to submit the listing. 5. Observe the confirmation popup message displayed after saving.


## ❌ Actual Result
The popup displays an incorrect time value — “You can only revoke and update the listing within 0 minutes.”

## ✅ Expected Result
The popup should display the correct duration for modification.
