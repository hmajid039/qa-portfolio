## 🐞 Description
While creating a listing, the shipping address is automatically pre-filled even though the user has not enabled the shipping address toggle.

## 🔁 Steps to Reproduce
1. Log in to theBynfor ios(qacomet3) 2. Start creating a new listing 3. Do not enable the “same as a store Address” toggle 4. Observe the shipping address section


## ❌ Actual Result
Shipping address fields are pre-filled automatically without toggle activation.

## ✅ Expected Result
Shipping address fields should remain empty until the user explicitly enables the toggle.
