## 🐞 Description
When a logged-in individual user attempts to checkout a product from the cart, the checkout interface does not appear. The page remains blank with no error message, blocking the order process.

## 🔁 Steps to Reproduce
1. Login with an individual account 2. Add any product to the cart 3. Open the cart page 4. Click on the Checkout button


## ❌ Actual Result
Checkout page opens with no interface displayed. The screen appears blank and the user cannot proceed with the order.

## ✅ Expected Result
Checkout page should load successfully and display order summary, address details, and payment options so the user can complete the purchase.
