## 🐞 Description
When a user creates a Gallery Event listing, it is displayed correctly. However, upon creating another Gallery Event listing, the previously created listing disappears from the event listings. This results in data visibility loss and prevents users from viewing multiple events.

## 🔁 Steps to Reproduce
1. Go to BynFor Admin panel and log in 2. Navigate to Gallery Events 3. Create a new Gallery Event listing (Event A) 4. Verify that Event A is displayed on dev BynFor 5. Create another Gallery Event listing (Event B) 6. Check the Gallery Event listings


## ❌ Actual Result
Only the most recently created Gallery Event listing is shown; the previously created listing is no longer visible.

## ✅ Expected Result
All created Gallery Event listings should remain visible and listed together unless explicitly filtered or removed.
