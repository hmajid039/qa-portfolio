## 🐞 Description
On the Advertisement Listing page in Bynfor, the postal number input field allows users to enter alphabetic characters instead of restricting input to numeric values.

## 🔁 Steps to Reproduce
1. Log in to the Bynfor platform. 2. Go to the Advertisement Listing page. 3. Locate the Postal Number input field. 4. Enter alphabetic characters (e.g., “ABCD” or “12A4”). 5. Try to proceed or save the listing.


## ❌ Actual Result
The postal number field accepts alphabetic characters without any validation error.

## ✅ Expected Result
The postal number field should only accept numeric input and display an error message when characters are entered.
