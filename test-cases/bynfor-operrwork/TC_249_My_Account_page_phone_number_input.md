## 🐞 Description
On the My Account page, the phone number input field accepts an unlimited number of digits without validation. After saving and reopening the page, the phone number value appears as random characters instead of the entered number.

## 🔁 Steps to Reproduce


## ❌ Actual Result
The field accepts unlimited digits, and the saved phone number displays as encoded or random characters.

## ✅ Expected Result
The phone number field should only allow numeric input (0–9) with a maximum limit (e.g.15 digits), and it should display correctly when the page is reopened.
