## 🐞 Description
In the Fine Art listing flow on BynFor, selecting Upload Media via browser opens a new page that is completely blank with no options or controls, blocking users from uploading media.

## 🔁 Steps to Reproduce
1. Open BynFor app and log in 2. Navigate to Fine Art → Create/Edit Listing 3. Click on Upload Media via browser 4. Observe the redirected page


## ❌ Actual Result
A blank white page opens with no upload options or UI elements.

## ✅ Expected Result
The media upload page should display proper UI controls allowing users to select and upload media files.
