## 🐞 Description
When the seller edits an active Sealed Bid Beyond Listing, the Provenance field becomes empty, even though it was correctly filled during the original listing creation. Important listing data gets lost upon edit.

## 🔁 Steps to Reproduce
1. Go to BynFor and log in (Account: qacomet3) 2. Create a Beyond Listing → Sealed Bid type 3. Fill in all required fields, including Provenance 4. Submit and let the listing become Active 5. Now open the Active listing and click Edit 6. Check the Provenance field


## ❌ Actual Result
The Provenance field appears blank while editing, even though it was filled earlier.

## ✅ Expected Result
Provenance data should remain intact and pre-filled during edit mode for active Sealed Bid listings.
