## 🐞 Description
When the user creates a new group under Summary (in the Hamburger Menu) and saves it successfully, reopening the same group to edit displays a large blank grey block area on the screen.

## 🔁 Steps to Reproduce
1. Go to BynFor app and log In (Account: qacomet2) 2. Open the Hamburger Menu → Summary section 3. Click on Create Group and fill in the required details 4. Save the group successfully 5. Reopen the same group to edit


## ❌ Actual Result
A blank grey block area appears, and the group details are not visible for editing.

## ✅ Expected Result
The group’s previously saved details should load correctly in the edit view without any blank sections.
