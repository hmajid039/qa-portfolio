## 🐞 Description
When a user posts a comment on a Fine Art listing, the comment is automatically marked as liked even though the user did not click the Like button.

## 🔁 Steps to Reproduce
1. Go to BynFor app and log in (Account: qacomet3) 2. Navigate to any Fine Art listing 3. Add a comment in the comment section 4. Observe the like status of the newly added comment


## ❌ Actual Result
The comment is created with a Like already applied automatically.

## ✅ Expected Result
The comment should be created without any Like unless the user explicitly clicks the Like button.
