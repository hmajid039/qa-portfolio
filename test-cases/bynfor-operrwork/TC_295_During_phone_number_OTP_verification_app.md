## 🐞 Description
During phone number OTP verification, the app shows an error message stating “Check phone number” and fails to send the OTP SMS even when a valid number is entered. This blocks users from verifying their phone numbers and proceeding further.

## 🔁 Steps to Reproduce
1. Go to BynFor app and log in (Account: qacomet2) 2. Navigate to the Profile or Phone Verification section 3. Enter a valid phone number 4. Tap on Send OTP


## ❌ Actual Result
The app displays an error message “Check phone number” and does not send the OTP.

## ✅ Expected Result
The OTP should be sent successfully when a valid phone number is entered, allowing the user to verify their number.
