## 🐞 Description
On the “Buy Now” popup, when the user changes the language from the language selector, the system redirects to the login page instead of remaining on the same popup.

## 🔁 Steps to Reproduce
1. Log in to website.        2.Navigate to Instant Buy section   3. Click on a product    4. On the product page, click Buy Now.    5. Change the language from the toolbar while on the popup.


## ❌ Actual Result
User is redirected to the login page, and the popup is closed.

## ✅ Expected Result
Language change should not affect the current state, the popup should remain open, and text should be translated.
