## 🐞 Description
While creating a Gallery Event from admin side, a start and end date range can be selected. However, on the user-facing Bynfor website, only the start date is displayed for the event. This creates a mismatch between admin configuration and frontend display and may confuse users regarding event duration

## 🔁 Steps to Reproduce
1. Login to Bynfor Admin panel 2. Create a Gallery Event 3. Select Start Date and End Date range 5. Save the event 6. Open the event on the website


## ❌ Actual Result
Only the start date is shown on the frontend; the end date is not displayed

## ✅ Expected Result
Full date range (Start Date – End Date) should be displayed on user frontend if supported
