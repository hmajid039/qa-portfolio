## 🐞 Description
On the Store Plans page, when the user has an active Silver plan, the plans that are lower should display “Downgrade” and the plans that are higher should display “Upgrade.” However, the Gold Plan (which is higher than Silver) incorrectly displays the “Downgrade” button instead of “Upgrade.” This creates confusion and prevents correct plan switching.

## 🔁 Steps to Reproduce
1. Go to BynFor and Log in to the application. 2. Navigate to Store Plans. 3. Activate/ensure active plan is Silver. 4. View all available plans (Bronze, Silver, Gold, etc.). 5. Observe the button labels shown under each plan.


## ❌ Actual Result
The Gold plan displays the “Downgrade” button instead of “Upgrade.”

## ✅ Expected Result
Since Gold is a higher-level plan than Silver, the Gold plan should show the “Upgrade” button.
