## 🐞 Description
After creating and confirming a new listing, the app redirects to the Active Listings page. However, this page fails to load all previously created active listings and only displays the newly added one. This limits the user’s ability to view or manage older active listings, causing confusion about which listings are still live.

## 🔁 Steps to Reproduce
1. Go to the BynFor app and log in (Account: qacomet3). 2. Create a new listing and complete all required details. 3. Confirm the listing to activate it. 4. Observe the Active Listings page shown after confirmation.


## ❌ Actual Result
The Active Listings page only displays the most recent listing, hiding previously active listings.

## ✅ Expected Result
The Active Listings page should display all active listings, including previously created ones and the newly added listing.
