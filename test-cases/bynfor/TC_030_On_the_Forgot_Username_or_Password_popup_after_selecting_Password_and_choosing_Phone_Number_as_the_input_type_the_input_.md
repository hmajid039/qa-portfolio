## 🐞 Description
On the “Forgot Username or Password?” popup, after selecting Password and choosing Phone Number as the input type, the input field still displays Email or Username and allows entering an email or username instead of a phone number.

## 🔁 Steps to Reproduce
1. Go to the homepage.              2.Click Sign In.                 3.Click Forgot Username or Password?  4.Select Password under “I Forgot My.”   5.Choose Phone Number as Input Type.


## ❌ Actual Result
The input field label shows “Email or Username” and accepts email/username input instead of a phone number.

## ✅ Expected Result
The field label and validation should correspond to Phone Number — user should only be able to enter digits as a phone number.
