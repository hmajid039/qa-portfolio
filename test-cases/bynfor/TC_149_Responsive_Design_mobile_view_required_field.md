## 🐞 Description
In the Responsive Design (mobile view), the required field indicators (asterisks *) for the Username and Password fields on the Registration page are not properly aligned. The asterisks appear on the boundary edge of the input fields

## 🔁 Steps to Reproduce
1. Open the Registration page on a mobile device 2. Observe the Username and Password field labels.


## ❌ Actual Result
Asterisks appear on the boundary line of the input fields, making the layout look misaligned.

## ✅ Expected Result
Asterisks (*) should be properly aligned inside the field labels (Username, Password), maintaining clear spacing and consistent alignment across all views.
