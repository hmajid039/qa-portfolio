## 🐞 Description
On the Create Variation popup for listing item, the section labeled “Attributes and options you've selected: Drag to rearrange” suggests that users can drag and reorder the attributes or options. However, the drag-and-drop functionality is not working. The user is unable to rearrange the position of attributes like Color or Size, or their options.

## 🔁 Steps to Reproduce
1. Loging to desktop website.   2. Go to List an item page.   3.Open the Create Variations popup. 4. Add multiple attributes (e.g., Color, Size) and their respective options. 5. Try to drag and rearrange the added attributes or options under the section “Attributes and options you've selected: Drag to rearrange.”


## ❌ Actual Result
Dragging attributes or options does not work. The system does not allow reordering.

## ✅ Expected Result
Users should be able to drag and rearrange the order of attributes and options as indicated by the instruction.
