## 🐞 Description
On the Create a Listing page, when a user selects the Auto Relist checkbox, a Days input box appears. The box is unnecessarily large, and the numbers typed inside align to the left edge, making the UI look awkward and poorly formatted

## 🔁 Steps to Reproduce
1.Go to the Bynfor web application and log in. 2. Navigate to Profile → Listing → Create Listing. 3. Select the Auto Relist checkbox. 4. Observe the Days input box that appears. 5. Type a number into the box and notice the alignment.


## ❌ Actual Result
The Days input box is too large, and typed numbers align to the left edge, giving a weird and inconsistent appearance.

## ✅ Expected Result
The Days input box should be reasonably sized and numbers should be centered or properly padded for better readability and UI consistency.
