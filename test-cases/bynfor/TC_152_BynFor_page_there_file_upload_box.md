## 🐞 Description
On the BynFor page, there is a file upload box with a placeholder for file name at the top and an upload icon at the bottom. Currently, clicking anywhere on the box — whether on the placeholder text, images inside the box, or the upload icon — immediately triggers the file upload dialog, which may lead to unintentional uploads

## 🔁 Steps to Reproduce
1. Go to the BynFor and log in 2. Click on the profile icon and click on Report to BynFor 3. Locate the file upload box with the placeholder and upload icon. 4. Click on the placeholder text,  images above the box, or the upload icon.


## ❌ Actual Result
Clicking anywhere on the box, above or below the box immediately opens the file upload dialog.

## ✅ Expected Result
Clicking on the upload icon should trigger the file upload dialog. Clicking on the placeholder or other non-interactive areas should not trigger file upload to prevent accidental actions.
