## 🐞 Description
In the Store Information page under the Selling section on the desktop version, the Referrers dropdown does not display an asterisk (*) initially. The asterisk only appears after the user selects any option from the dropdown. This behavior is inconsistent and may confuse users, as required field indicators should be visible before user interaction.

## 🔁 Steps to Reproduce
1. Open the web application on a desktop and login(as a Indivisual/Business) 2. Navigate to Selling → Store Information. 3. Locate the Referrers dropdown. 4. Observe the field before selecting any option. 5. Select an option from the dropdown and observe the asterisk appearing.


## ❌ Actual Result
The asterisk (*) appears only after selecting an option from the “Referrers” dropdown.

## ✅ Expected Result
If the field is required, the asterisk should be visible by default before selection. If not required, it should not appear at all after selection.
