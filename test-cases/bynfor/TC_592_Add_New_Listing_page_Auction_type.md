## 🐞 Description
On the Add New Listing page (Auction type), typing in the Provenance field and clicking the text clears the input unexpectedly. This can result in accidental data loss

## 🔁 Steps to Reproduce
1. Open Bynfor Android app (e.g., majidbusiness / Sun@Ray123) 2. Go to Seller Area → My Listings, click “+” to add new listing 3. Select Auction as listing type 4. In the Provenance field, type any text (e.g., “New Stock”) 5. Click on the text and observe


## ❌ Actual Result
The text in the Provenance field clears automatically

## ✅ Expected Result
The text should remain in the Provenance field; the user should be able to type, edit, or place the cursor without losing input
