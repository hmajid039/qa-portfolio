## 🐞 Description
On the Become a Partner page, the Referral section has an Add button. Clicking this button automatically adds a specific referral name without providing any option for the user to select or enter a referral.

## 🔁 Steps to Reproduce
1. Log in to BynFor 2. Navigate to Partnership Programme → Become a Partner 3. Go to the Referral section 4. Click on the Add button


## ❌ Actual Result
A predefined referral name is added automatically without user input or selection.

## ✅ Expected Result
User should be able to select or enter a referral name, or no referral should be added by default.
