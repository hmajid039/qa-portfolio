## 🐞 Description
On the simple listing page for Real Estate listing page, the embedded map does not update or adjust according to the country selected by the user. Additionally, the map is positioned above the address field instead of appearing after it.

## 🔁 Steps to Reproduce
1. Go to Listing page → Create Simple Listing → Real Estate category.  2. Select any country (e.g., United States or Pakistan).  3.Observe the map displayed on the page.


## ❌ Actual Result
The map remains static and does not adopt the selected country. It is also displayed before the address field.

## ✅ Expected Result
The map should dynamically adjust to reflect the selected country’s location and should be displayed after the address field for better usability and logical flow.
