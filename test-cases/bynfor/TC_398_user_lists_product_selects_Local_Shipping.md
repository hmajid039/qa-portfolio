## 🐞 Description
When the user lists a product and selects the Local Shipping option, the full address entered during the listing process is not displayed in the preview screen. Instead, only the postal code appears. This causes incomplete information to be shown to the user and may lead to confusion or incorrect listing details.

## 🔁 Steps to Reproduce
1. Go to BynFor and log in (Account: qacomet3) 2. Go to Listing and create a new product listing 3. Select Local Shipping option 4. Enter full address  5. Proceed to the Preview step 6. Observe the displayed shipping address details


## ❌ Actual Result
The preview shows only the postal code, while the full address entered by the user is missing.

## ✅ Expected Result
The preview should display the complete address exactly as entered: Street, City, State, and Postal Code.
