## 🐞 Description
When clicking the List to Event button in the Fine Art Gallery, the system loads a reused user profile/gallery component showing posts, followers, and following stats instead of navigating to an event-specific page. This results in incorrect UI, user confusion, and breaks the expected event listing flow.

## 🔁 Steps to Reproduce
1, Go to BynFor app and log in (Account: qacomet3) 2. Navigate to Fine Art Gallery 3. Click on the List to Event button 4. Observe the page content that loads


## ❌ Actual Result
A user gallery/profile-style page is displayed with social stats (Posts, Followers, Following) instead of an event-related screen.

## ✅ Expected Result
The List to Event button should navigate to an event-specific view (event listing or event creation flow) relevant to listing artwork in an event, without loading profile/gallery components.
