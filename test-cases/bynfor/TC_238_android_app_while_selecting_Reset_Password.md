## 🐞 Description
In the android app while selecting the “Reset Password via Phone” option, there is no input field to enter the phone number. Due to this, users cannot proceed with password recovery via phone.

## 🔁 Steps to Reproduce
1. Open the Bynfor app on android.         2 Navigate to the Login page. 3. Click on “Forgot Username or Password.”    4. Select Password.   5. Select Phone as Input type.         6. Press continue. 7. Observe that there is no field available to enter a phone number.


## ❌ Actual Result
Phone number input field is missing under “Reset Password via Phone” option.

## ✅ Expected Result
A phone number input field should be present so users can enter their registered number to reset the password.
