## 🐞 Description
When the user creates a Sealed Bid, the “Acceptable Reserve Price” dropdown has no placeholder text at all. The field appears completely empty and never shows any hint or label unless the user clicks the dropdown. This makes the field unclear and reduces usability because the user cannot understand what input is expected.

## 🔁 Steps to Reproduce
1. Go to BynFor app and log in (Account: qacomet3) 2. Go to Listing and create a new listing 3. Select the Sealed Bid radio button 4. Scroll to the “Acceptable Reserve Price” dropdown 5. Observe the field before clicking it


## ❌ Actual Result
The dropdown field appears blank with no placeholder text.

## ✅ Expected Result
A placeholder (e.g., “Select Reserve Price”) should be displayed by default to indicate the purpose of the field before user interaction.
