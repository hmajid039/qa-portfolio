## 🐞 Description
The confirmation message for folder deletion displays two question marks, which makes the text look grammatically incorrect and inconsistent with UI writing standards.

## 🔁 Steps to Reproduce
1. Go to the https://www.bynfor.com/summary/messages          2. Create a folder.               3. Click the delete (trash) icon next to created folder.    4. Observe the confirmation popup text


## ❌ Actual Result
Popup displays as “Are you sure you want to remove this folder? MY FOLDER?” (two question marks).

## ✅ Expected Result
Popup should display as “Are you sure you want to remove this folder ‘MY FOLDER’?” with only one question mark and proper quotation formatting.
