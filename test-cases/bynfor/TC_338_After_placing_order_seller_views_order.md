## 🐞 Description
After placing an order, when the seller views the order information, the tracking number is not displayed. This prevents the seller from accessing important shipment details and may affect order processing and customer updates.

1. Open a bynfor (Account used : qacomet3)                      2. Place an order using a buyer account. 3. Log in to the seller account associated with the order. 4. Navigate to the order information/details page. 5. Check the tracking number field.


## ❌ Actual Result
The tracking number should be visible in the order details for the seller immediately after the order is placed.

## ✅ Expected Result
The tracking number field is empty or missing from the order details
