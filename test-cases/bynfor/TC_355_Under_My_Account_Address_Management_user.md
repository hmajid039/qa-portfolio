## 🐞 Description
Under My Account → Address Management, when the user updates the country, state, and postal code fields, and then types in the Address field, the auto-suggestion list still shows address options from other countries. This causes confusion and increases the chances of incorrect address selection.

## 🔁 Steps to Reproduce
1. Go to Bynfor log in and click on the My Profile icon. 2. Select My Account. 3. Go to Address Management. 4. Update Country, State, and Postal Code fields. 5. Start typing in the Address field. 6. Observe the auto-suggested address options.


## ❌ Actual Result
The system shows address suggestions belonging to other countries, even after the user selects a specific country and region.

## ✅ Expected Result
The address suggestions should be filtered and displayed only based on the selected Country, State, and Postal Code.
