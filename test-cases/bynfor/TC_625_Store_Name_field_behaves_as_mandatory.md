## 🐞 Description
The Store Name field behaves as a mandatory field, as the system displays an error when it is not selected. However, unlike other required fields in the form, it is not marked with a red asterisk (*) can make it unclear to users that the field is required before submission

## 🔁 Steps to Reproduce
1. Log in to the Bynfor dev(majidbusiness / Sun@Ray123) 2. Navigate to Avatar → Partnership Programs → Distributor Partnership 3. Observe no visible indicator for it store name being mandatory 4. Do not select any store name 5. Click on Submit for Review


## ❌ Actual Result
Store Name is required, but no visual indicator (*) is shown

## ✅ Expected Result
If the Store Name field is mandatory, it should be marked with a red asterisk (*) to indicate it is required before submission, like other required fields
