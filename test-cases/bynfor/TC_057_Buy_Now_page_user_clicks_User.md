## 🐞 Description
On the Buy Now page, when the user clicks on the User Agreement link in the Order Summary section, the agreement correctly opens in a new tab. However, the original tab unexpectedly reloads and redirects the user to the Home page instead of remaining on the Buy Now page.

## 🔁 Steps to Reproduce
1. Log in to website. 2 Go to INSTANT BUY.  3. Click on any product. 4. Click on BUY NOW. 5.On the Order Summary section, click the User Agreement link.  5.Observe the behavior on the original tab.


## ❌ Actual Result
The User Agreement opens in a new tab, but the original tab reloads and redirects to the Home page.

## ✅ Expected Result
The User Agreement should open in a new tab while the original Buy Now page remains unchanged.
