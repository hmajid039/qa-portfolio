1. Open the"https://dev.bynfor.com/home"  on a mobile browser. 2. Check the header section for available categories. 3. Compare with the Desktop Web header.

The categories Sealed Bid, Reverse Bid, Instant Buy, and Auction Events are missing from the header in the Phone Web view.

## ✅ Expected Result
All main header categories should be visible and accessible in the Phone Web view, similar to the Desktop Web version.
