## 🐞 Description
When a user is on the Business Registration page and changes the language using the language selector, the system redirects to the Sign In page instead of remaining on the Business Registration page with the selected language applied.

## 🔁 Steps to Reproduce
1. Open Bynfor website on desktop.   2. Click on Register and select Business Account.   3. Change the languge from language selecter dropdown.   4. Observe the behavior of the page.


## ❌ Actual Result
The user is redirected to the Sign In page after changing the language, instead of staying on the registration form.

## ✅ Expected Result
The page should remain on the Business Registration page, only the language should change according to the user’s selection.
