## 🐞 Description
When a user copies the URL from a product page and pastes it elsewhere (e.g., in a browser, chat, or notes), the copied link only displays as “BynFor” instead of the full product URL. This prevents users from sharing or reopening specific product pages directly, affecting product discoverability and link sharing functionality.

## 🔁 Steps to Reproduce
1. Go to the BynFor app and log in (Account: nikitatesteraccount). 2. Open any product page under Instant Buy or Active Listings. 3. Copy the page URL from the address bar or using the share option. 4. Paste the copied URL in any text field (e.g., browser, notes, or chat).


## ❌ Actual Result
The copied link only displays the text “BynFor,” not the actual product URL, making the shared link non-functional.

## ✅ Expected Result
The copied link should contain the full product URL so users can directly open the same product page when pasted or shared.;;;
