## 🐞 Description
On the Listing page, under Return Provided By selection, there is an Instructions text box. When a user enters minimal text (e.g., a single word) and fills the rest of the form, attempting to list the product does not save the listing. The page highlights the Instructions box with a red outline, but no error or warning message is shown to guide the user on the required input. This causes confusion and disrupts the listing process.

## 🔁 Steps to Reproduce
1. Go to the Bynfor web application and log in. 2. Navigate to the Listing page. 3. Under Return Provided By, fill the necessary fields. 4. Enter minimal text (e.g., one word) in the Instructions text box. 5. Complete the rest of the listing form and attempt to submit/list the product. 6. Observe that the listing is not saved, and the Instructions box is outlined in red without any error message.


## ❌ Actual Result
The listing fails to save, the Instructions box gets a red outline, but no error or warning message is displayed.

## ✅ Expected Result
A clear error or warning message should appear specifying the required format or minimum content for the Instructions box to guide the user.
