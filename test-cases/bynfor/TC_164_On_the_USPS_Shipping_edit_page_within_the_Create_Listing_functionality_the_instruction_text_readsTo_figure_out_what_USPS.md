## 🐞 Description

“To figure out what USPS services are available for you to offer to customers, please out the information below.”

“To figure out what USPS services are available for you to offer to customers, please fill out the information below.”

1. Go to the Bynfor web application and log in. 2. Navigate to Profile → Listing → Create Listing. 3. Go to the USPS Shipping edit page. 4. Observe the instruction text above the input fields.


## ❌ Actual Result
The instruction text is missing the word “fill”, making it read incorrectly as “please out the information below.”

## ✅ Expected Result
The instruction text should correctly read:

“To figure out what USPS services are available for you to offer to customers, please fill out the information below.”
