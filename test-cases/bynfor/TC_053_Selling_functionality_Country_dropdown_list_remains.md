## 🐞 Description
In the Selling functionality, the Country dropdown list remains in English even after selecting another language.

## 🔁 Steps to Reproduce
1. Open the application and select any non-English language. 2. Navigate to the account>seller 3. Open the Country dropdown.


## ❌ Actual Result
Country names in the dropdown remain in English despite selecting another language.

## ✅ Expected Result
All country names in the dropdown should appear in the selected language for a consistent user experience.
