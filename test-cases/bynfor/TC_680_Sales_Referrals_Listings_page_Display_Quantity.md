## 🐞 Description
On the Sales Referrals with Listings page, the Display Quantity dropdown automatically selects 20 by default even when lower values such as 5 and 10 are already available. This results in an unexpected default selection.

## 🔁 Steps to Reproduce
1. Go to BynFor app and log in (Account: qacomet3) 2. Navigate to Sales Referrals 3. Open Sales Referrals with Listings page 4. Observe the Display Quantity dropdown


## ❌ Actual Result
The Display Quantity is auto-selected as 20 by default, ignoring lower available options (5, 10).

## ✅ Expected Result
The default Display Quantity should select the lowest available value (e.g., 5 or 10) or follow a defined default behavior.
