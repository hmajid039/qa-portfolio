## 🐞 Description
When a user creates a detailed listing and clicks on preview, the first preview shows only an image placeholder instead of the actual product image. On refreshing or clicking preview again, the image loads correctly. This can confuse users and impacts the listing creation experience.

## 🔁 Steps to Reproduce
1. Go to Bynfor and Log in to the seller account(Account used: qacomet3). 2. Create a detailed listing with images. 3. Click on the “Preview” button for the first time. 4. Observe the image section in the preview. 5. Click preview again or refresh the page.


## ❌ Actual Result
The first preview shows only an image placeholder; the actual images load only on subsequent previews.

## ✅ Expected Result
The product images should display correctly on the first preview attempt.
