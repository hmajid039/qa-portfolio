## 🐞 Description
When the user is on the Gold Store Plan payment page and clicks the browser’s Back button, the system redirects them to the “Get a Plan” page rather than taking them back to the previous page they navigated from. This behavior interrupts the natural navigation flow and can confuse users who expect to return to their last visited page.

## 🔁 Steps to Reproduce
1. Navigate to the Gold Store Plan payment page.   2.Click on the browser back arrow.


## ❌ Actual Result
Clicking the Back button redirects the user to the “Get a Plan” page instead of the Plan selecting page.

## ✅ Expected Result
User should be redirected to the plan selecting page instead of the page loaded.
