## 🐞 Description
The “Remember Me” label is clickable and toggles the checkbox when clicked. The checkbox should only be checked when the user clicks directly inside the checkbox area, not on the text. Also, the cursor does not change from an arrow to a hand pointer when hovering over the checkbox.

## 🔁 Steps to Reproduce
1. Go to the Login page (https://dev.bynfor.com/index)    2. Hover over the “Remember Me” text        3. Click on the text instead of the checkbox


## ❌ Actual Result
Clicking on the text “Remember Me” automatically checks/unchecks the checkbox. Cursor remains as an arrow instead of changing to a hand pointer.

## ✅ Expected Result
Checkbox should only be checked when clicked directly. Cursor should change to a hand pointer when hovering over the checkbox.
