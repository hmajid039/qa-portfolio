## 🐞 Description
On the Store Layout page, the numbering format for sub-menus is inconsistent and unclear. For example, under Menu2, the sub-menus are currently labeled as Sub-Menu21 and Sub-Menu22 instead of a hierarchical format like 2.1 and 2.2. Similarly, under Category2, the numbering of menus and sub-menus should follow a structured pattern (e.g., 2.1, 2.2, 2.1.1, etc.) for better readability

## 🔁 Steps to Reproduce
1. Loging to website.      2. On the listing page select Settings.    3.Select a template that has a menu option, such as Men’s store. 4.Observe the menu hierarchy displayed under the “Menu” section. 5.Check how sub-menus and categories are labeled.


## ❌ Actual Result
Sub-menu numbering is displayed as Sub-Menu21, Sub-Menu22, etc.  Not following a structured or parent-based numbering format.

## ✅ Expected Result
Sub-menus should follow a hierarchical numbering format to indicate their relationship with parent menus and categories. For example:
Menu 2.1, Menu 2.2
Category 2.1, Category 2.2
Sub-Menu 2.1.1, Sub-Menu 2.1.2, etc.
