## 🐞 Description
On the Listing → Variation page, when a user clicks the Variation button and adds variations, buttons like Delete and Price open a popup where users can fill values directly. The title of the Price popup currently uses a font that appears messy and affects readability.

## 🔁 Steps to Reproduce
1. Go to the Bynfor web application and log in. 2. Navigate to the Listing page. 3. Click on the Variation button. 4. Add some variations. 5. Click on the Price button to open the popup. 6. Observe the font of the title in the popup.


## ❌ Actual Result
The Price popup title uses a font that looks messy and unprofessional.

## ✅ Expected Result
The Price popup title should use a clean, readable, and visually consistent font with the rest of the page UI.
