## 🐞 Description
When a user clicks a notification, it is marked as read. However, clicking “Mark as Read” again causes the same notification to switch back to unread briefly (radio button), then shows as read.

## 🔁 Steps to Reproduce
1. Go to Bynfor ios and login(qacomet3)  and Open Notifications 2. Click on an unread notification 3. Click “Mark as Read” on the same notification


## ❌ Actual Result
Notification temporarily changes to unread (radio button visible) before showing as read again.

## ✅ Expected Result
Notification should remain in read state consistently without switching back to unread.
