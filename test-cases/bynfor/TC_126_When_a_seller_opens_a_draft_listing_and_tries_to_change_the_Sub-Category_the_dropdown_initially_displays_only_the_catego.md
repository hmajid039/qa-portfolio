## 🐞 Description
When a seller opens a draft listing and tries to change the Sub-Category, the dropdown initially displays only the category names. Users must first click on a category to expand it before the nested subcategories become visible. This extra step makes the selection process less intuitive and can confuse users.

## 🔁 Steps to Reproduce
1. Go to the Bynfor web application and log in. 2. Click on the Profile icon and then click on the Listing button. 3. Open any draft listing. 4. Click on the Sub-Category field to change it. 5. Observe the dropdown content and attempt to select a subcategory.


## ❌ Actual Result
The dropdown shows only category names at first. Users must click on a category to view and select subcategories.

## ✅ Expected Result
The dropdown should display all relevant subcategories directly or provide a more intuitive way to select a subcategory without requiring an extra click.
