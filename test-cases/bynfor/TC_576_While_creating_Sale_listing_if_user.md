## 🐞 Description
While creating a Sale listing, if the user enables Auto-list and sets the number of days, the value is not retained on the Edit listing page.

## 🔁 Steps to Reproduce
1. Go to the BynFor app and log in (Account: qacomet3) 2. Create a Sale listing 3. Enable Auto-list and enter days 4. Publish the listing 5. Open the listing and navigate to Edit


## ❌ Actual Result
Edit page shows only the Auto-list checkbox

Days field is hidden

When user taps Auto-list, days input appears but is empty

## ✅ Expected Result
Auto-list days should be pre-filled and visible on the edit page when Auto-list is enabled.
