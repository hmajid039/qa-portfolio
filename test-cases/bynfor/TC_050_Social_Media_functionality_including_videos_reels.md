## 🐞 Description
The Social Media functionality, including videos/reels, member names, titles, and content, is not translated into the selected language.

## 🔁 Steps to Reproduce
1. Open the application and select a non-English language. 2. Navigate to the Social Media section. 3. Check all videos/reels, member names, titles, and content for translation.


## ❌ Actual Result
All content in Social Media, including videos/reels, member names, and other text, remains in English despite selecting another language.

## ✅ Expected Result
All elements within the Social Media functionality, including videos/reels, member names, and content, should display in the selected language.
