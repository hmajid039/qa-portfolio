## 🐞 Description
On the Basic Seller Account page, there are two separate sections, each with its own Save & Apply button. However, clicking Save & Apply in one section also affects the other section or does not save the intended section individually.If each has seperate button so user should be able to fill each part and cleck on save and apply without requiring to fill entire form.

## 🔁 Steps to Reproduce
1. Log in to the application as a seller. 2. Navigate to the Basic Seller Account page. 3. Make changes in the first section and click its Save & Apply button. 4. Observe whether changes are applied only to that section. 5.Repeat the steps for the second section.


## ❌ Actual Result
Clicking Save & Apply in one section after filling that part still shows  warning "Please fill all necessary fields." Even all mandatory information of that part is filled.

## ✅ Expected Result
Each Save & Apply button should save changes only for its respective section, allowing independent updates.
