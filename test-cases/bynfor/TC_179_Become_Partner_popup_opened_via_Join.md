## 🐞 Description
On the “Become a Partner” popup (opened via “Join Now” link under Customer Return Policy), all three checkboxes 

1.Auto Fill Personal Information
2.I Agree with the Term and Conditions
3.I understand I will not get commission before I pay for nominal verification 
can be checked by clicking on the text label next to them, not just the checkbox area.

## 🔁 Steps to Reproduce
1.Go to the Listing Page. 2.Scroll down to the Customer Return Policy section. 3.Click the Join Now link to open the “Become a Partner” popup. 4.Click on the text next to each checkbox.


## ❌ Actual Result
Checkboxes toggle state (checked/unchecked) when user clicks on the text label.

## ✅ Expected Result
Checkboxes should only toggle when the user clicks directly on the checkbox, maintaining consistency with other pages.
