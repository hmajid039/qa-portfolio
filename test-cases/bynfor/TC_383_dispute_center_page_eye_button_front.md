## 🐞 Description
On the "dispute center" page, the “eye” button in front of each case is displayed in gray color on the "Against" tab. This visual issue may mislead users into thinking the button is disabled or not clickable, even though it is functional. For the similar view, eye appears blue in "By Me" tab for the user who created the dispute

## 🔁 Steps to Reproduce
1. Log in as a seller (majidbusiness / Sun@Ray123) 2. Navigate to My Account →  Dispute Center 3. Navigate to Against tab 4. Observe the eye button color


## ❌ Actual Result
The “eye” button is gray for Against tab view, giving the impression it cannot be clicked

## ✅ Expected Result
The button should have the same color (blue) as other action buttons to indicate it is clickable, or use consistent UI cues for disabled vs enabled buttons
