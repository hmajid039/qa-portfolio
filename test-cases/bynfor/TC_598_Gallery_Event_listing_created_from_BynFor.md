## 🐞 Description
When a Gallery Event listing is created from the BynFor Admin panel with both start and end dates defined, the event listing on the dev BynFor site displays only the start date. The end date is not shown, causing incomplete event duration information.

## 🔁 Steps to Reproduce
1. Go to BynFor Admin panel and log in 2. Navigate to Gallery Events 3. Create a new Gallery Event listing 4. Add a valid Start Date and End Date 5. Save the event 6. Open the event listing on dev BynFor


## ❌ Actual Result
Only the event start date is displayed; the end date is not visible on the listing.

## ✅ Expected Result
Both start date and end date should be displayed clearly on the Gallery Event listing to reflect the full event duration.
