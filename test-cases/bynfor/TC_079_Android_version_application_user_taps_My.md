## 🐞 Description
On the Android version of the application, when a user taps the My Account icon (top-right corner), a dropdown menu appears with several functionalities such as Selling, Wallet, etc.
After navigating to any tab under the dropdown, the menu does not close automatically.
The user must tap elsewhere on the screen to close the dropdown, which affects usability and is inconsistent with expected behavior.

## 🔁 Steps to Reproduce
1. Open the application on an Android device. 2. Tap the My Account icon at the top-right corner. 3. Observe that a dropdown menu appears showing multiple functionalities (Selling, Wallet, etc.). 4. Tap on any functionality/tab in the dropdown. 5. Notice that the dropdown remains open and does not close automatically. 6. Tap anywhere else on the screen to finally close the dropdown.


## ❌ Actual Result
Dropdown menu under My Account remains open after navigating to a functionality/tab.

Requires the user to click elsewhere on the screen to close it manually.

## ✅ Expected Result
Dropdown menu should close automatically after the user selects any functionality/tab under My Account.

Provides a smooth and intuitive navigation experience
