## 🐞 Description
On the Listing page, when a user clicks on Service subcategory options, the popup displaying the available choices shows duplicate radio buttons for each option. This creates confusion and makes the UI inconsistent.

## 🔁 Steps to Reproduce
1. Go to the Bynfor web application and log in. 2. Navigate to Profile → Listing → Service. 3. Click on a Service subcategory to open the options popup. 4. Observe the radio buttons displayed for each choice.


## ❌ Actual Result
Each option in the Service subcategory popup displays two radio buttons instead of one.

## ✅ Expected Result
Each option should display only a single radio button for selection. Duplicate radio buttons should be removed.
