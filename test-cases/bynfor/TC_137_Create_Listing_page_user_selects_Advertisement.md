## 🐞 Description
On the Create a Listing page, when the user selects the Advertisement option, the dropdown displays several sub-options. However, some options are missing the forward arrow (→) indicator, and when clicking on the arrow for other options, the dropdown list shifts awkwardly to the right, causing layout distortion and misalignment.

## 🔁 Steps to Reproduce
1. Go to the Bynfor web application and log in. 2. Click on the Profile icon and navigate to Listing → Create Listing. 3. select Advertisement. 4. Observe the dropdown options displayed. 5. Click on any available forward arrow (→) beside an option.


## ❌ Actual Result
Some options in the dropdown are missing forward arrows.

When clicking on arrows for existing options, the dropdown shifts to the right in a disorganized manner

## ✅ Expected Result
All relevant dropdown options should have forward arrows if sub-options exist.

Dropdown alignment should remain consistent without any shifting or misplacement.
