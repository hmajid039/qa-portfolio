## 🐞 Description
In the My Store section, when the user updates the phone number country code to United States (+1), the incorrect flag is displayed. This may cause confusion for users and may lead to incorrect assumption about the selected country code.

## 🔁 Steps to Reproduce
1. Open the Bynfor and go to the My Store section. 2. Click on the Phone Number field. 3. Change the country code from any other country to the United States (+1). 4. Observe the flag displayed next to the selected US country code.


## ❌ Actual Result
An incorrect or different country flag is displayed instead of the US flag.

## ✅ Expected Result
When selecting United States (+1), the US flag (🇺🇸) should be correctly displayed.
