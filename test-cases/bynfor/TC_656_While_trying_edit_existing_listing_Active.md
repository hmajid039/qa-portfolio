## 🐞 Description
While trying to edit an existing listing in the Active tab of My Listing, the app unexpectedly closes and returns to the phone’s home screen, and prevents users from updating their listings

## 🔁 Steps to Reproduce
1. Open Bynfor Android app (majidbusiness / Sun@Ray123) 2. Go to Seller Area → My Listing → Active tab 3. Select an existing listing and click the Edit button 4. Observe the listing form opening 5. App crashes and the home screen of the phone is shown 6. Repeat 2–3 times to confirm


## ❌ Actual Result
The app crashes and closes when attempting to edit a listing

User is returned to the phone’s home screen

## ✅ Expected Result
The listing form should open without issues

Users should be able to edit and update their listings without the app crashing
