## 🐞 Description
In the desktop version of the application, when logged in with a Business Account, attempting to update the store logo opens the file browser as expected. However, after selecting or browsing a file, the page automatically redirects to the unfilled fields section instead of staying on the upload logo area.

## 🔁 Steps to Reproduce
1. Log in to the desktop application using a Business Account. 2. Navigate to Selling → Store Information. 3. Click on the Store Logo section to update the logo. 4.Observe the page behavior it is not staying in logo update section


## ❌ Actual Result
After opening the file browser and selecting/canceling a file, the page redirects automatically to the unfilled fields section instead of staying in the upload logo section.

## ✅ Expected Result
The page should remain in the upload logo section until the logo upload is completed or canceled. It should not redirect automatically.
