## 🐞 Description
In the android BynFor app, When a partnership request is rejected from the Business Account, the rejection notification is not displayed within the Distributor Partnership module of the Individual Account. The rejection is only visible in the Notifications section, and the user must manually open the notification to confirm the rejection. Additionally, there is no clear option available to resend the same partnership request from the module.

## 🔁 Steps to Reproduce
1. Open the BynFor Android app 2. Select Create Individual Account 3. Fill in the required details 4. Agree to the Terms and Conditions 5. Submit the form


## ❌ Actual Result
The rejection status is not shown in the Distributor Partnership module. The rejection is only visible through the notification panel, and the user must open the notification manually to confirm the rejection. No clear option is available to resend the same partnership request.

## ✅ Expected Result
The rejected partnership request should be clearly displayed in the Distributor Partnership module with its rejection status, and the user should be provided with a visible option to resend the partnership request directly from the module.
