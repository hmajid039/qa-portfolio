## 🐞 Description
When the user changes the application language, not all UI modules are translated. Some sections, labels, or modules continue to display text in the previously selected language, causing an inconsistent user interface.

## 🔁 Steps to Reproduce
1. Login to the application 2. Open Home page 3. Change the language (e.g., English to Arabic) 4. Navigate through different modules/screens


## ❌ Actual Result
Only some UI text is translated to the selected language while other modules still appear in the previous language. The interface becomes partially translated and confusing for the user.

## ✅ Expected Result
All UI elements, modules, labels, buttons, and messages should update immediately and consistently to the selected language across the entire application.
