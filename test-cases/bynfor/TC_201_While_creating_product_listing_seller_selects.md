## 🐞 Description
While creating a product listing, when the seller selects the Local Pickup shipping option, no additional input fields (such as price, handling time, or pickup details) appear. In other shipping options the system shows corresponding input fields.

## 🔁 Steps to Reproduce
1. Log in as a seller on BynFor. 2. Go to Create Listing. 3. In the Shipping Options section, select Local Pickup. 4. Observe that no field appears to add price or pickup-related details.


## ❌ Actual Result
When selecting Local Pickup, no additional field appears to specify price or related details.

## ✅ Expected Result
Selecting Local Pickup should display an additional field to enter pickup-related details (e.g., price, instructions, estimated time, etc.), similar to how other shipping options function.
