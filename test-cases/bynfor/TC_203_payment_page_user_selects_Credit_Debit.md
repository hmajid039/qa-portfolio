## 🐞 Description
On the payment page, when a user selects the Credit/Debit Card option, the label "Select card for payment" appears in an incorrect location instead of above the card details input section.

1. Go to BynFor and log in as a seller. 2. Navigate to Create Listing and complete listing details. 3.Proceed to the Payment page. 4. Select the Credit/Debit Card radio button. 5. Observe the placement of the "Select card for payment" label.


## ❌ Actual Result
The "Select card for payment" label appears in the wrong place, not aligned above the card details section.

## ✅ Expected Result
The "Select card for payment" label should appear correctly above the card details input fields for clarity and proper UX.
