## 🐞 Description
When changing the language from the Individual Account Registration page using the language selector, the user is incorrectly redirected to the Login page instead of remaining on the registration page in the selected language.

## 🔁 Steps to Reproduce
1. Open the website from desktop.    2. Click on Register.  3. From Individual Registration page change the language from language selecter.


## ❌ Actual Result
After changing the language, the page redirects to the Login page instead of staying on the registration page.

## ✅ Expected Result
The page should stay on the Individual Registration page, updating the text to the selected language.
