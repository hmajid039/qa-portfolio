## 🐞 Description
On the Service Create Listing page, under the Product Specifics section, the Detailed Description field indicates “2000 words remaining”, but there is no visible text box for the user to enter the description. This prevents users from adding necessary information about the service.

## 🔁 Steps to Reproduce
1. Go to the Bynfor web application and log in. 2. Navigate to Profile → Listing → Create Listing → Service. 3. Scroll down to the Product Specifics section. 4. Observe the Detailed Description field indicating “2000 words remaining”.


## ❌ Actual Result
The Detailed Description field shows the word count remaining but does not provide a text box for user input.

## ✅ Expected Result
A visible and editable text box should be provided under Detailed Description to allow users to enter up to 2000 words.
