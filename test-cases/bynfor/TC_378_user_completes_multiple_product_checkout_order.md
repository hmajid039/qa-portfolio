## 🐞 Description

The alignment of rows and columns is distorted — totals appear repeated for each product, and empty spaces break the table structure. This creates a confusing and unprofessional checkout summary layout.

## 🔁 Steps to Reproduce
1. Go to Bynfor and log in (Account Used: qacomet3). 2. Add multiple products to the cart. 3. Proceed to checkout and complete the purchase. 4. Observe the Order Confirmation Summary page.


## ❌ Actual Result
1. The summary layout appears misaligned.
2. The total value ($11,252.15) repeats for each product instead of showing respective totals.
3. Empty columns and spacing issues cause broken alignment in the table.
4. Overall, the summary looks inconsistent and visually cluttered.

## ✅ Expected Result
1. The order summary should display products in a clean, structured table format.
2. Each product should show Photo, Name, Price, and Invoice in properly aligned columns.
3. Each product’s total value should correspond correctly without repetition.
