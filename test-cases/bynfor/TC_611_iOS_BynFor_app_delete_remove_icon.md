## 🐞 Description
In the iOS BynFor app, the delete/remove icon for the store logo is missing on the Store Creation page. This option is available on the Web BynFor, leading to inconsistent behavior and preventing users from removing an uploaded logo on iOS.

## 🔁 Steps to Reproduce
1. Open BynFor iOS app and log in 2. Navigate to Create Store 3. Upload a store logo 4. Observe the logo section for a delete/remove icon


## ❌ Actual Result
No delete/remove icon is shown for the uploaded store logo on iOS.

## ✅ Expected Result
A delete/remove icon should be available, similar to Web BynFor, allowing users to remove or change the store logo during store creation.
