## 🐞 Description
On the Listing page, users can upload more than 12 product images for a listing. The system does not display any error or warning about exceeding the maximum limit, which violates the stated restriction of allowing only up to 12 images.

## 🔁 Steps to Reproduce
1. Go to the Bynfor web application and log in. 2. Click on the Profile icon and navigate to the Listing page. 3. Open a draft listing or create a new listing. 4. Attempt to upload more than 12 product images.


## ❌ Actual Result
The system allows uploading more than 12 images without showing any error or validation message.

## ✅ Expected Result
The system should restrict the number of product images to 12 and display a clear error or warning if the user tries to upload more.
