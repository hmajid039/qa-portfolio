## 🐞 Description
On the Android version of the application, under Selling → Fine Arts Gallery, the page content is not locked.
Users are able to drag or swipe the page in unintended ways, which can affect layout consistency and user experience. The page should remain fixed while scrolling within content areas

## 🔁 Steps to Reproduce
1. Open the application on an Android device. 2. Navigate to Selling → Fine Arts Gallery. 3. Attempt to drag the page horizontally


## ❌ Actual Result
Page content can be dragged in unintended directions.

Layout appears inconsistent and user experience is affected.

## ✅ Expected Result
The page should be locked; only intended scrollable areas (like content lists) should move.

Page layout should remain stable while navigating content.
