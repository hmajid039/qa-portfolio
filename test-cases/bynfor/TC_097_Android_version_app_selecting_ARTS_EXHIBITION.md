## 🐞 Description
On the Android version of the app, selecting the “ARTS EXHIBITION” option from the menu incorrectly redirects the user to the Home screen instead of the intended ARTS EXHIBITION page.

## 🔁 Steps to Reproduce
1. Launch the Android app.   2. Open the main menu.  3. Tap on “ARTS EXHIBITION.”    4. Observe the redirection.


## ❌ Actual Result
The app redirects the user to the Home screen.

## ✅ Expected Result
The app should open the ARTS EXHIBITION page showing related exhibitions or content.
