## 🐞 Description
In the List Draft section, each listing format option (e.g., Sale, Reverse Bid, Best Offer, etc.) shows an extra radio button within the selection.

## 🔁 Steps to Reproduce
1. Go to the Bynfor web application and log in. 2. Navigate to the Selling section. 3. Open the List Draft page. 4. Observe the listing format options (Sale, Reverse Bid, Best Offer, etc.).


## ❌ Actual Result
Each listing format option displays an extra radio button inside it, making the UI confusing and selection inconsistent.

## ✅ Expected Result
Each listing format option should have only a single radio button to ensure correct selection.
