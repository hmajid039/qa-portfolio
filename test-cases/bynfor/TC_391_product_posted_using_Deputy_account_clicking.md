## 🐞 Description
When a product is posted using a Deputy account, clicking the Edit (pencil) icon on the listed product does not open the product editing page. Instead, the user is redirected to the Personal Information page.

## 🔁 Steps to Reproduce
1.Log in using a Deputy account (deputyuser2/Sun@Ray123). 2. List an item successfully. 3. Go to the Unverified page 4. Click the Edit icon on the posted item.


## ❌ Actual Result
The system redirects to the Personal Information page instead of the product edit page.

## ✅ Expected Result
The system should redirect the user to the Product Edit page so that the product listing can be updated.
