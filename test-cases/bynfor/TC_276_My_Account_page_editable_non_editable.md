## 🐞 Description
On the My Account page, the editable and non-editable fields are not visually or functionally consistent. The Username and Email Address fields are correctly non-editable but appear active since they are not visually faded or disabled. In contrast, the Phone Number field — which should be editable — is currently non-editable. Additionally, within the same field, the country code (+1) is displayed in normal text color, whereas the phone number appears faded

## ❌ Actual Result
Username and Email Address fields are not editable but do not appear visually disabled.
Phone Number field is non-editable, though it should be editable.
Country code (+1) and Phone Number text are displayed in inconsistent color tones.

## ✅ Expected Result
Non-editable fields should appear visually disabled (e.g., greyed out).
The Phone Number field should be editable to allow users to update their contact information.
Both country code and phone number should have consistent visual styling.
