## 🐞 Description
While adding store information on the Seller page (logged in as a business account), pressing the initial letter of a country in the country code dropdown doesn’t navigate to the correct country. For example, pressing “Z” for Zimbabwe jumps to countries starting with “S” instead. The correct country only appears when typing two letters (e.g., “ZI”).

## 🔁 Steps to Reproduce
1. Log in as a business account.   2. Go to the Seller page → Get a Plan.   3.Click on the Country Code dropdown.    4.Press the first letter of a country (e.g., “Z” for Zimbabwe).


## ❌ Actual Result
Pressing the first letter navigates to an incorrect section of the dropdown list (e.g., “S” instead of “Z”).

## ✅ Expected Result
The dropdown should correctly jump to the country that matches the first pressed letter (e.g., pressing “Z” should directly highlight countries starting with Z).
