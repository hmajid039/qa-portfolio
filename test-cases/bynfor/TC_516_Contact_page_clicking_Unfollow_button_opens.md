## 🐞 Description
On the Contact page, clicking the Unfollow button opens a popup that says “Do you want to Unblock this person?” The popup message is misleading, as the user action is to unfollow, not unblock. This may confuse users about the action they are performing

## 🔁 Steps to Reproduce
1. Open the Bynfor app android(appuser / Sun@Ray123) 2. Navigate to the Contact page 3. Locate a user that is currently followed 4. Click the Unfollow button 5. Observe the popup message displayed


## ❌ Actual Result
Popup message shows “Do you want to UnBlock this person?”

## ✅ Expected Result
Popup message should clearly correspond to the action, e.g., “Do you want to Unfollow this person?”
