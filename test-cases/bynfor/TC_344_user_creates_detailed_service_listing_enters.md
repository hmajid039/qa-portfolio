## 🐞 Description
When the user creates a detailed service listing and enters a phone number in the contact information field, the phone number is not displayed correctly in the preview. Instead of showing the actual number, the preview displays the text: Telephone Number: [object Object]. This affects clarity for users reviewing their listing before publishing.

## 🔁 Steps to Reproduce
1. Go to Bynfor and log in (Account Used: qacomet3). 2. Create a new Detailed Service Listing. 3. Enter all required listing details, including a valid phone number in the Telephone field. 4. Save the listing and proceed to the Preview section. 5. Observe the displayed telephone number in the preview.


## ❌ Actual Result
The preview displays: Telephone Number: [object Object]

## ✅ Expected Result
The preview should display the actual phone number entered
