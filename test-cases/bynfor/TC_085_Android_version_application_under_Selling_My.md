## 🐞 Description
On the Android version of the application, under Selling → My Store, the Map always displays the US map, even when the user selects India as the store location and clicks Save & Apply.

## 🔁 Steps to Reproduce
1. Open the application on an Android device. 2. Navigate to Selling → My Store. 3. Select India as the store location on the Map. 4. Click Save & Apply. 5. Observe that the Map still displays the US map instead of India.


## ❌ Actual Result
Map always shows the US region regardless of selected or saved location.

## ✅ Expected Result
Map should correctly display the selected and saved location (e.g., India) after applying changes.
