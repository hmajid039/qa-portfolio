## 🐞 Description
When a user attempts to unregister their store plan, the confirmation message displayed is grammatically incorrect and confusing. The message reads: “You are about to unregister your store plan, please be advised that any available listings will be not available no more. Do you want to proceed to unregister your Store Plan?” This may confuse users about the consequences of unregistering their plan.

## 🔁 Steps to Reproduce
1. Go to the Bynfor web application and log in. 2. Click on the Profile icon and navigate to the Selling section. 3. Go to Store Plan management or Become a Seller section. 4. Select a plan and attempt to unregister your store plan. 5. Observe the confirmation message displayed.


## ❌ Actual Result
The message is grammatically incorrect and contains a double negative, making it unclear to users.

## ✅ Expected Result
The message should be grammatically correct, clear, and user-friendly, clearly explaining that all active listings will no longer be available if the user proceeds.
