## 🐞 Description
When the user checks or unchecks the “Same as Store Address” checkbox in the Address Information section, a small white vertical box appears briefly beside the checkbox, which seems like a UI glitch or rendering issue.

## 🔁 Steps to Reproduce
1. Login to the website. 2. Go to Seller Page → Store Information / Address Information. 3. Click on Purchase Store plans under Store Plan Information section.  4 Select Gold as under Store Plan section.   5.Select Credit/Debit card under Payment Method section. 6. Click on the label text  “Same as Store Address” instead of the checkbox itself under the Card Billing address..


## ❌ Actual Result
A white vertical box appears when the checkbox is checked/Unchecked.

## ✅ Expected Result
No extra visual element should appear when the checkbox is checked or unchecked.
