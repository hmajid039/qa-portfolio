## 🐞 Description
On the Listing page under the Listing Audience section, tooltips meant to describe the radio button options (e.g., Only Friends, Only Followers, Only Group) are not displaying consistently. Sometimes the tooltip does not appear at all or disappears too quickly, making it difficult for users to understand the purpose of each option.

## 🔁 Steps to Reproduce
1. Go to the Bynfor web application and log in. 2. Navigate to Profile → Listing → Create Listing. 3. Scroll to the Listing Audience section. 4. Hover over or click on the radio buttons for Only Friends, Only Followers, or Only Group.


## ❌ Actual Result
The tooltip appears inconsistently — sometimes it does not show up, or it disappears before the user can read it.

## ✅ Expected Result
The tooltip should appear reliably when the user hovers over or focuses on each radio button and remain visible long enough to read its content.
