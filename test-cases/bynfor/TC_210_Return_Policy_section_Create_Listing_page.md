## 🐞 Description
On the Return Policy section of the “Create Listing” page, all standard policy options start with lowercase letters (e.g., “returns within 7 days of delivery”), except for the last option “No Returns Accepted,” which starts with a capital letter.

## 🔁 Steps to Reproduce
1. Login to Bynfor desktop version.    2. Go to listing page.   3.Scroll to the Return Policy section. 4.Observe the text of the listed standard return policy options.


## ❌ Actual Result
The last option “No Returns Accepted” starts with a capital “N,” while all other options start with lowercase “r.”

## ✅ Expected Result
All return policy options should follow consistent capitalization formatting.
