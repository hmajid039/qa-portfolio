## 🐞 Description
On the Service Create Listing page, under the Service Information section, the Available Day dropdown has its text and dropdown icon overflowing outside the dropdown box.

## 🔁 Steps to Reproduce
1. Go to the Bynfor web application and log in. 2. Navigate to Profile → Listing → Create Listing → Service. 3. Scroll to the Service Information section. 4. Locate the Available Day dropdown. 5. Observe that the text and dropdown icon are not properly contained within the dropdown box.


## ❌ Actual Result
The text and dropdown icon of the Available Day dropdown are overflowing outside the dropdown box, making it look unprofessional and harder to use.

## ✅ Expected Result
The Available Day dropdown should properly contain both the text and the dropdown icon within the box boundaries, ensuring clear visibility and proper alignment.
