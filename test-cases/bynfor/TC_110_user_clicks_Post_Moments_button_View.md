## 🐞 Description
When a user clicks the “Post Moments” button on the View Store page, the Social Moments page opens. However, the store logo is completely missing on this page, which affects store branding and visual consistency.

## 🔁 Steps to Reproduce
1. Open the web application on a desktop browser. 2.Log in using a Business or Individual account. 3. Navigate to Selling → Store Information and ensure a store has a logo uploaded. 4. Click the View Store button. 5. Click the “Post Moments” button on the View Store page. 6.Observe the Social Moments page for the presence of the store logo.


## ❌ Actual Result
The store logo is entirely missing on the Social Moments page

## ✅ Expected Result
The store logo should be displayed on the Social Moments page, consistent with the branding shown on other store pages.
