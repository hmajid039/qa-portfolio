## 🐞 Description
When the user changes the language from the home page, the change is partially applied. Some tabs and menu items remain in the previous language while other sections update correctly.

## 🔁 Steps to Reproduce
1. Go to home page of the website.              2. Change the language from the language selector on the home page.  3. Navigate through various tabs and menu options.


## ❌ Actual Result
Only certain parts of the site  update to the selected language, while some tabs and menu items remain in English.

## ✅ Expected Result
All site content, including tabs, menus, and sections, should update according to the selected language.
