## 🐞 Description
When selecting subcategories under the Real Estate and Services categories on the “List an Item” page, each option displays two radio buttons instead of one, and both are clickable.

## 🔁 Steps to Reproduce
1.Go to the Seller Center from sidebar menu.                                 2. Select List an item. 3.Navigate to List an Item → Real Estate or Services. 4. Observe the subcategory selection popup.                5.Check the display of radio buttons beside each subcategory option.


## ❌ Actual Result
Each subcategory option displays two radio buttons instead of one.

## ✅ Expected Result
Each subcategory option should display only one radio button.
