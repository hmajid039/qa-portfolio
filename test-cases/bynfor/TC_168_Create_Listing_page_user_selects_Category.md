## 🐞 Description
On the Create Listing page, when a user selects the Category as Real Estate and clicks on any Subcategory, a popup appears titled “Choose how you want to list your Real Estate”. Each option in this popup displays duplicate radio buttons, which causes confusion and affects UI consistency.

## 🔁 Steps to Reproduce
1. Go to the Bynfor web application and log in. 2. Navigate to Profile → Listing → Create Listing. 3. Select Category → Real Estate. 4. Click on any Subcategory. 5. Observe the popup “Choose how you want to list your Real Estate”.


## ❌ Actual Result
Each option in the Real Estate listing popup has two radio buttons instead of one.

## ✅ Expected Result
Each option should have only one radio button to select the listing type. The extra duplicate radio buttons should be removed.
