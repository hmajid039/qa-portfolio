## 🐞 Description
On the Store Templates page, the upper section labeled “Menu” (which includes options for menu, banners, and categories) is visible only when selecting Generic Template or Men’s Store. For all other template types like., Food and Beverage, Book Store, Women’s Store, etc, only the “Pick Store Layout” visual layout section is displayed.

## 🔁 Steps to Reproduce
1.Log in to Bynfor website. 2. Navigate to Seller page from sidebar. 3.Go to the Settings tab. 4. From the Templates dropdown, select: “Generic Template” → both upper and lower layout sections appear. “Men’s Store” → both upper and lower layout sections appear. Any other template (e.g., “Food and Beverage,” “Book Store”) → only the lower “Pick Store Layout” section is visible.


## ❌ Actual Result
Only Generic Template, abc, Textile, Danny Test Template and Men’s Store display both layout configuration sections, upper “Menu and lower “Pick Store Layout”.

## ✅ Expected Result
All templates should consistently display both layout sections, or there should be a clear message/tooltip explaining why the upper layout section is available only for certain templates.
