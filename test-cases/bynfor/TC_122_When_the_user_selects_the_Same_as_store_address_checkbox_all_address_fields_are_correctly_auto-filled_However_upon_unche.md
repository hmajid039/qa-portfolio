## 🐞 Description
When the user selects the “Same as store address” checkbox, all address fields are correctly auto-filled. However, upon unchecking the box, the fields remain populated instead of clearing out

## 🔁 Steps to Reproduce
1. Login to the website. 2. Go to Seller Page → Store Information / Address Information. 3. Click on Purchase Store plans under Store Plan Information section.  4 Select Gold as under Store Plan section.   5.Select Credit/Debit card under Payment Method section. 6. Check the “Same as Store Address” checkbox under the Card Billing address.   4.Uncheck the checkbox.


## ❌ Actual Result
The address fields stay filled even after unchecking the checkbox.

## ✅ Expected Result
Unchecking the “Same as store address” checkbox should clear the address fields, allowing manual input.
