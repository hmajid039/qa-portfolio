## 🐞 Description
On the checkout page, users can add and select from multiple credit/debit cards, but there is no option to add more than one bank account for payment. The functionality is inconsistent compared to card payment options.

## 🔁 Steps to Reproduce
1.Go to the checkout page.  2.Under Select Payment Method, choose Credit/Debit Card.  3.Observe that multiple cards can be added.  4.Now select Bank Account as the payment method.  5.Observe that only one bank account can be added and selected.


## ❌ Actual Result
Only a single bank account can be added for payment.

## ✅ Expected Result
Users should be able to add and select from multiple bank accounts, similar to the credit/debit card section.
