## 🐞 Description
In the Find Username field, entering any text does not display matching user suggestions. When the Add button is clicked, the system directly adds the entered text as a username, even if it is partial or non-existing (e.g., qa).

## 🔁 Steps to Reproduce
1. Go to BynFor app and log in (Account: qacomet3) 2. Navigate to Sales Referrals 3. Click on Find Username 4.  Enter a partial or random name (e.g., qa) 5.  Click on Add


## ❌ Actual Result
The entered text is added directly as a username without showing any selectable user options or validation.

## ✅ Expected Result
The system should display a list of matching existing usernames and allow selection only from valid users.
