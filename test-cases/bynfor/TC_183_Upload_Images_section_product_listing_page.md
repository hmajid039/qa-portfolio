## 🐞 Description
On the “Upload Images” section of the product listing page, there is a large white space between the “Select Default Image” heading and the radio buttons used for selecting the default image.

## 🔁 Steps to Reproduce
1. Login to Bynfor website from desktop.       2. Navigate to the Upload Images section while creating a new product listing. 3.Upload multiple product images.  4. Observe the gap between the “Select Default Image” heading and the radio buttons below the images.


## ❌ Actual Result
There is a large empty white space between the heading and the radio buttons, causing misalignment and unclear grouping.

## ✅ Expected Result
The “Select Default Image” heading should be closely aligned with the corresponding radio buttons for a cleaner and more intuitive layout.
