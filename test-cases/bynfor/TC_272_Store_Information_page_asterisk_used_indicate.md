## 🐞 Description
On the Store Information page, the asterisk (*) used to indicate required fields appears inconsistent. Most fields (e.g., Address, City, Postal Code) use a grey asterisk matching the label color, whereas the Store Plan field uses a red star (★) instead of a standard asterisk.

## 🔁 Steps to Reproduce


## ❌ Actual Result
Most fields have a grey asterisk (*) matching the label color. The “Store Plan” field uses a red star (★) instead of an asterisk.

## ✅ Expected Result
All mandatory fields should use a consistent indicator (preferably red asterisk) to clearly show that they are required.
