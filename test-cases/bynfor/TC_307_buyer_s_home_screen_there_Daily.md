## 🐞 Description
On the buyer’s home screen, there is a Daily Credit Reward link. When the user clicks Collect, a message appears stating “You are not eligible for this.” However, the app does not specify any reason for ineligibility, leaving the user unsure about the criteria or required actions to qualify. This creates confusion and a poor user experienc

## 🔁 Steps to Reproduce
1. Go to the BynFor app and log in as a buyer (Account: nikitatesteraccount). 2. On the home screen, locate the Daily Credit Reward link. 3. Tap on Collect. 4. Observe the response message displayed.


## ❌ Actual Result
The app only shows the message “You are not eligible for this” without explaining the reason for ineligibility.

## ✅ Expected Result
If the user is not eligible, the app should clearly mention the reason — such as “You have already collected today’s reward,” “Your account doesn’t meet the eligibility criteria,” or “Please complete verification first.”
