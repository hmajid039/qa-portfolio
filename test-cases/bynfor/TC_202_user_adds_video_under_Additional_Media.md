## 🐞 Description
When a user adds a video under the “Additional Media” section on the Create Listing page, removes it, and then tries to add the same video again, the upload fails or does not allow re-selection.

## 🔁 Steps to Reproduce
1. Go to BynFor and log in as a seller (Individual or Business account). 2. Click on the Profile icon and go to Listing → Create Listing page. 3. Scroll down to the Additional Media section. 4. Click on Add Video and upload any video file. 5. Remove the uploaded video. 6. Try adding the same video file again.


## ❌ Actual Result
The system does not allow re-uploading the same video file once it has been removed.

## ✅ Expected Result
The user should be able to re-upload the same video file after removing it.
