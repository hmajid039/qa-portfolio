## 🐞 Description
When a buyer places an automatic bid on a Beyond Million listing (above Reserve Price), the bid is correctly allotted. However, the success message shows “Hi {{user}}” instead of displaying the buyer’s actual name.

## 🔁 Steps to Reproduce
1. Log in as a buyer on BynFor(qacomet3) 2. Place an automatic bid on a Beyond Million listing above Reserve Price 3. Observe the success message


## ❌ Actual Result
Message displays “Hi {{user}}” instead of the buyer’s name.

## ✅ Expected Result
Message should display the buyer’s actual name.
