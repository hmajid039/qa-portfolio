## 🐞 Description
On the Android version of the application, under Selling → Fine Arts Gallery, the following elements are disabled and not interactable:

Fine Art Gallery checkbox

Gallery Subscriptions checkbox

Subscription box

Users are unable to select or modify these options, which affects the functionality of subscriptions and gallery management.

## 🔁 Steps to Reproduce
1. Open the application on an Android device. 2. Navigate to Selling → Fine Arts Gallery. 3. Observe the Fine Art Gallery and Gallery Subscriptions checkboxes. 4. Observe the Subscription box. 5. Attempt to select or modify these elements — note that they are disabled and cannot be interacted with.


## ❌ Actual Result
Checkboxes and the subscription box are disabled and cannot be selected or modified.

## ✅ Expected Result
Users should be able to check/uncheck Fine Art Gallery and Gallery Subscriptions checkboxes.

The subscription box should be enabled and fully interactable for managing subscriptions.
