## 🐞 Description
On the mobile app "About Your Listing" page, the "Title" field displays a character counter of 0/200 but allows users to enter more than 200 characters (e.g., 214+)

## 🔁 Steps to Reproduce
1. Open Bynfor android app(majidbusiness / Sun@Ray123) 2. Go to Seller Area -> My Listng -> Sale 3. Locate the Title field showing 0/200 4. Enter text exceeding 200 characters (e.g., 214 characters) 5. Observe the character counter and input behavior


## ❌ Actual Result
The Title field allows typing beyond 200 characters while the counter continues increasing past the defined limit

## ✅ Expected Result
The Title field should enforce the mentioned 200-character limit. Input beyond 200 characters should be blocked, and the counter should not exceed 200
