## 🐞 Description
When the user requests a password reset in the iOS app, the received password reset email is poorly formatted.

## 🔁 Steps to Reproduce
1. Open the iOS app. 2. Navigate to the Login page. 3. Tap Forgot Username/Password → select Forgot Password. 4. Enter a valid registered email address and continue. 5. Check the inbox for the password reset email.


## ❌ Actual Result
The reset password email content is misaligned

## ✅ Expected Result
The reset password email should be properly aligned with consistent spacing, centered call-to-action button, and clear text formatting for a professional appearance.
