## 🐞 Description
When registering a new user, the phone number field does not allow entering the full number. The input stops before the last digit, likely due to limited input field length.

## 🔁 Steps to Reproduce
1. Go to the user registration page.   2.Enter a phone number in the phone number field.     3Try typing the complete number.


## ❌ Actual Result
The field does not accept the last digit of the phone number.

## ✅ Expected Result
The phone number field should allow the complete number to be entered without restriction.
