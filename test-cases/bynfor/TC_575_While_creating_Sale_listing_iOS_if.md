## 🐞 Description
While creating a Sale listing on iOS, if the user selects No Return as the return policy, the final active listing incorrectly displays “Return back fee paid by buyer”.

## 🔁 Steps to Reproduce
1. Go to BynFor app and log in (Account: qacomet3) 2. Create a Sale listing on iOS 3. Set Return Policy to No Return 4. Complete listing creation 5. Open the listing from Active Listings


## ❌ Actual Result
Active listing shows return policy as No return but also showing  “Return back fee paid by buyer”.

## ✅ Expected Result
Active listing should display No Return as selected during listing creation.
