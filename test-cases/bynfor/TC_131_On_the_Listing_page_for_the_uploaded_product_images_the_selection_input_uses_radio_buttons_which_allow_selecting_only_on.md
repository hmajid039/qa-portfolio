## 🐞 Description
On the Listing page, for the uploaded product images, the selection input uses radio buttons, which allow selecting only one image at a time. Users should be able to select multiple images, so checkboxes should be used instead. Using radio buttons limits functionality and can confuse users.

## 🔁 Steps to Reproduce
1. Go to the Bynfor web application and log in. 2. Click on the Profile icon and navigate to the Listing page. 3. Open a draft listing or create a new listing. 4. Upload multiple product images. 5. Attempt to select multiple images from the uploaded set.


## ❌ Actual Result
Users can select only one image at a time because radio buttons are used.

## ✅ Expected Result
Users should be able to select multiple images simultaneously using checkboxes for selection.
