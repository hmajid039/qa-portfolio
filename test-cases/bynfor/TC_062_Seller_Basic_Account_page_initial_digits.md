## 🐞 Description
On the Seller Basic Account page, the initial digits of the phone number are partially covered by the country code field.

## 🔁 Steps to Reproduce
1. Log in and click on the profile icon. 2. Click on Selling  3. Navigate to the My Store account page. 4. Fill Phone number on phone field


## ❌ Actual Result
The initial digits of the phone number are hidden or overlapped by the country code field.

## ✅ Expected Result
The Country Code and Phone Number fields should be clearly separated, allowing the entire phone number to be visible and editable without obstruction.
