## 🐞 Description
On the Templates page, when a user clicks on a Sub-Menu under any menu (e.g., Menu1 → Sub-Menu1), the fields on the right-hand side (used to enter data or select products) appear, but they are not writable or editable. The user cannot add or update data in these boxes.

## 🔁 Steps to Reproduce
1. Loging to website.                   2. On the listing page select Settings.                           3.Select a template that has a menu option, such as Men’s store. 4.Expand a menu section (e.g., Menu1) and click on a Sub-Menu (e.g., Sub-Menu1). 5.Observe the boxes appearing on the right-hand side of the screen. 6.Try typing or interacting with the fields.


## ❌ Actual Result
The right-side input fields under Target Menu: Sub-Menu are displayed but cannot be written into or edited. Also no response is received when trying to click or type in the boxes.

## ✅ Expected Result
The fields under the Target Menu: Sub-Menu section should be writable so that users can enter or update data.
