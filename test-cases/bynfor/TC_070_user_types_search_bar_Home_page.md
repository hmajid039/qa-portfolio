## 🐞 Description
When a user types in the search bar on the Home page, the entered text appears dim and has low contrast, making it difficult to read. The text should be clearly visible against the background for better usability.

## 🔁 Steps to Reproduce
1.Go to the Home page.    2.Click inside the search bar.   3. Type any keyword inside it.


## ❌ Actual Result
Text inside the search bar appears faded and lacks proper contrast, making it difficult to see while typing.

## ✅ Expected Result
Typed text should be clearly visible and have sufficient contrast against the background.
