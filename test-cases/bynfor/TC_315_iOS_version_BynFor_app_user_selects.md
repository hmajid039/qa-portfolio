## 🐞 Description
In the iOS version of the BynFor app, when the user selects the “Auto Relist” checkbox while creating or editing a listing, the corresponding “Days” textbox (for specifying relist duration) does not appear. This prevents users from setting how long the listing should auto-relist, reducing control over listing behavior.

## 🔁 Steps to Reproduce
1. Open the BynFor app on iOS and log in (Account: qacomet3) 2. Go to create a new listing or edit an existing one 3. Scroll to the “Auto Relist” option and check the checkbox 4. Observe that no “Days” textbox appears to input duration


## ❌ Actual Result
When the user checks the “Auto Relist” option, a textbox labeled “Days” should appear, allowing users to enter the relist duration.

## ✅ Expected Result
The “Days” textbox does not appear after selecting the “Auto Relist” checkbox, leaving the setting incomplete.
