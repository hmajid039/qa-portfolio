## 🐞 Description
On the iOS app login screen, when a user enters an incorrect password, the error message displayed is “Oops, wrong credential.” This wording is vague and unprofessional. It does not clearly inform the user which field (username or password) is incorrect, leading to confusion during login attempts.

## 🔁 Steps to Reproduce
1. Open the iOS app. 2. Navigate to the Login page. 3. Enter a valid username and an incorrect password. 4. Tap Login.


## ❌ Actual Result
The system displays the message: “Oops, wrong credential.”

## ✅ Expected Result
The app should display a clear, user-friendly message such as:
“Incorrect password. Please try again.”
or
“Invalid username or password. Please check your details and try again.”
