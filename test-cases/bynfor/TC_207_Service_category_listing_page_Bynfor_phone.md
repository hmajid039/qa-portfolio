## 🐞 Description
On the Service category listing page in Bynfor, the phone number input field allows users to enter more than 10 digits. There is no validation or error message displayed, which can lead to incorrect contact information being saved.

## 🔁 Steps to Reproduce
1. Log in to the Bynfor platform. 2. Click on the Profile icon and select Listing. 3. Select the Service category. 4. Enter a phone number with more than 10 digits in the phone number field. 5. Try to proceed or save the listing.


## ❌ Actual Result
The phone number field accepts more than 10 digits without showing any validation error.

## ✅ Expected Result
The phone number field should restrict input to a maximum of 10 digits and show an error message if more digits are entered.
