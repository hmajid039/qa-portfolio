## 🐞 Description
On the Store Information page, the Store Purchase Plan field is marked as essential (with an asterisk *), but it appears after the Save button. Users cannot select a store plan until the information is saved, and the purchase button remains unclickable initially. Despite this, the page allows saving store information without selecting a mandatory store plan.

## 🔁 Steps to Reproduce


## ❌ Actual Result
The Store Plan (marked as required) appears after the Save button, and the system allows saving store information even without selecting the plan.

## ✅ Expected Result
The Save button should be placed before the “Store Purchase Plan” section so that users can save store details first and then proceed to purchase the plan. Additionally, the system should not allow saving if the required store plan is not selected.
