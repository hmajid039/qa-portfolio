## 🐞 Description
When a seller creates a best offer listing and sets any custom price, the final published listing does not reflect the entered price. Instead, it always displays a generic estimated price range of “$1–$1000”, which misleads buyers and makes listings appear inaccurate.

## 🔁 Steps to Reproduce


## ❌ Actual Result
The published listing displays an estimated price range “$1–$1000” instead of the actual price set by the seller.

## ✅ Expected Result
The published listing should accurately show the exact price entered during the best offer creation.
