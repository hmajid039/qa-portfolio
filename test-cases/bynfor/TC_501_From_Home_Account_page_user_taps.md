## 🐞 Description
From the Home → Account page, when the user taps the Edit icon beside the profile section, the app immediately closes and returns to the Android home screen. This indicates application crash, preventing the user from accessing the Edit page

## 🔁 Steps to Reproduce
1. Open the Bynfor mobile app 2. From the home screen, tap Account 3. On the Account page, tap the Edit (pencil) icon beside the Profile section 4. Observe that the app immediately closes


## ❌ Actual Result
The app crashes instantly upon tapping the Edit icon, user is taken back to the Android home screen, app must be reopened manually

## ✅ Expected Result
The Profile Edit page should open normally without crashing, user should be able to update the relevant details
