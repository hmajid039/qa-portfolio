## 🐞 Description
While reviewing a partner application, the store owner is able to edit submitted fields (e.g., referral username). Reviewers should not be allowed to modify applicant-provided data, as this can affect referral relationships and commission logic

## 🔁 Steps to Reproduce
1. Open the Bynfor website majidbusiness / Sun@Ray123) 2. Open a pending "Become Store's Partner" request. Click the Blue Action icon for a pending user (e.g., "dua noor") 3. Locate the Referral input field (which is pre-filled) 4. Delete/Remove the text inside the Referral field so it is empty 5. Click the Accept button at the bottom 6. Click Yes on the confirmation pop-up


## ❌ Actual Result
The store owner can remove the username clicking on the x icon, giving impression that the request can be edited

## ✅ Expected Result
The store owner should only be able to view application details and approve or reject the request. Submitted data should be read-only
