## 🐞 Description
In the Real Estate listing form, the Postal Code field allows the user to enter more than 20 digits, which is invalid and can cause data issues.

## 🔁 Steps to Reproduce
1. Log in as a seller on BynFor 2. Navigate to Create Real Estate Listing 3. Enter more than 20 digits in the Postal Code field 4. Submit or save the listing


## ❌ Actual Result
Postal Code accepts input beyond 20 digits.

## ✅ Expected Result
Postal Code field should restrict input to 20 digits maximum.
