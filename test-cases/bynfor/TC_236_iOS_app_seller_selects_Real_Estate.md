## 🐞 Description
On the iOS app, when a seller selects the Real Estate category while creating a new listing, the Listing Format options (e.g., Fixed Price, Auction, or Best Offer) are missing.

## 🔁 Steps to Reproduce
1. Open the iOS app. 2. Log in with a Seller Account. 3. Navigate to Create Listing. 4. Choose the Real Estate category. 5. Observe that the Listing Format options are not visible.


## ❌ Actual Result
The Listing Format selection section is missing when creating a listing under the Real Estate category.

## ✅ Expected Result
The Listing Format options should be displayed for the Real Estate category, allowing sellers to select how they want to list their propert
