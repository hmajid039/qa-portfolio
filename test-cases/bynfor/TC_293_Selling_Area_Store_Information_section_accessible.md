## 🐞 Description
In the Selling Area → Store Information section (accessible from the Hamburger Menu), when the user clicks on Pick Store Plan, the page opens showing all available plans (Silver, Gold, Platinum). If the user has already chosen one plan (e.g., Silver), the Upgrade or Downgrade buttons for other plans (Gold or Platinum) are visible but not functional. Clicking on these buttons does not trigger any action or response.

## 🔁 Steps to Reproduce
1. Go to BynFor app and log In (Account: qacomet3) 2. Open the Hamburger Menu → Selling Area → Store Information 3. Click on Pick Store Plan 4. Observe the available plans (Silver, Gold, Platinum) 5.Click on Upgrade or Downgrade buttons for any plan other than the currently active one


## ❌ Actual Result
The Upgrade and Downgrade buttons are unresponsive and do not perform any action or redirect.

## ✅ Expected Result
Clicking on Upgrade or Downgrade should initiate the plan change process or display a confirmation prompt for switching the plan.
