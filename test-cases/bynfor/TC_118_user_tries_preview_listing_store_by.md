## 🐞 Description
When a user tries to preview a listing in the store by clicking the play/preview button, the system displays a “store image not found” error. This occurs even though the images appear to be correctly listed in the listing section, preventing users from previewing their store items properly.

## 🔁 Steps to Reproduce
1. Go to the Bynfor web application and log in. 2. Navigate to the Selling section. 3. Open a store listing that has images uploaded. 4. Click the play/preview button for the listing images.


## ❌ Actual Result
A “store image not found” error is displayed whick clicked on play button

## ✅ Expected Result
All uploaded images should be previewed properly when clicking the play/preview button.
