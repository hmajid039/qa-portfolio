## 🐞 Description
When a user creates a Sport Detailed Listing and saves it as a draft, the draft edit page does not provide a "List Item" button. Users should be able to directly list the item from the draft, but currently, this option is missing, forcing extra steps to publish the listing.

## 🔁 Steps to Reproduce
1. Go to Bynfor and log in (Account Used: qacomet3). 2. Create a new Sport Detailed Listing. 3. Fill in all required details for the listing. 4. Click on Save as Draft. 5. Navigate to the list of items/drafts and observe if the newly created draft appears.


## ❌ Actual Result
The "List Item" button is missing, preventing direct listing from the draft.while this button is present in other drafted listing.

## ✅ Expected Result
The draft edit page should display a "List Item" button, allowing the user to directly list the item from the draft.
