## 🐞 Description
On the Listing Draft page, even after filling all mandatory fields, sellers are unable to list the draft. The system does not provide any clear error message or indication of why the listing cannot be submitted, causing confusion and blocking the workflow.

## 🔁 Steps to Reproduce
1. Go to the Bynfor web application and log in. 2. Click on the Profile icon and navigate to Listing → Draft Listing. 3. Open a draft listing and ensure all mandatory fields are properly filled. 4. Attempt to list/publish the draft listing.


## ❌ Actual Result
The draft listing cannot be listed/published, and the system does not provide any error or warning message.

## ✅ Expected Result
The draft listing should be successfully listed once all mandatory fields are filled. If there is any issue, a clear error message should guide the user.
