## 🐞 Description
On the website, when a logged-in user clicks the Welcome Emoji icon next to the logo (which is intended for login/registration), the user is redirected to the “My Skill Content Reward” page instead of the expected “My Profile” page.

## 🔁 Steps to Reproduce
1. Log in with a valid user account. 2. Locate the Welcome Emoji icon next to the website logo. 3. Click on the Welcome Emoji icon.


## ❌ Actual Result
User is redirected to the “My Skill Content Reward” page.

## ✅ Expected Result
Clicking the Welcome Emoji icon while logged in should redirect the user to “My Profile” page.
