## 🐞 Description
When a user logs in with a business account on BynFor and proceeds to create a seller account, the State dropdown field unexpectedly shifts downward after selecting a country. This causes misalignment in the form layout and affects the visual consistency of the page.

## 🔁 Steps to Reproduce
1. Go to the BynFor website and log in as a Business Account user. 2. Click on the Profile Icon and select Create a Seller. 3. Fill in all other fields (e.g., name, email, address, etc.). 4. Scroll to the Country dropdown and select any country. 5. Observe the position of the State dropdown field after the country selection.


## ❌ Actual Result
After selecting a country, the State dropdown field shifts downward, breaking the form’s alignment.. Note: This behaviour is not consistent. Even after clearing the cache, this behavior persists.

## ✅ Expected Result
The State dropdown should remain in its correct position, maintaining a consistent layout even after a country is selected.
