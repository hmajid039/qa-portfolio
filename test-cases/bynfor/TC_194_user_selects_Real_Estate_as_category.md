## 🐞 Description
When a user selects Real Estate as the category while creating a new listing, the Sales Format option initially appears for a few seconds on the Create Listing page but then disappears automatically. This issue prevents users from selecting the desired sales format, impacting their ability to complete the listing setup properly.

## 🔁 Steps to Reproduce
1.Go to BynFor, log in, and click on the My Account icon. 2. Click on Listing. 3. Click on Create a Listing and select Real Estate as the category. 4. Observe that the Sales Format option appears briefly and then disappears after a few seconds.


## ❌ Actual Result
The Sales Format option is visible for a few seconds and then disappears automatically.

## ✅ Expected Result
The Sales Format option should remain visible and allow the user to select a format when the Real Estate category is selected.
