## 🐞 Description
On the Service Create Listing page, the Listing Format section (which usually allows selecting formats like Sale, Sealed Bid, Reverse Bid, etc.) is completely missing. Without this section, users cannot specify how they want to list their service, preventing proper listing configuration.

## 🔁 Steps to Reproduce
1.Go to the Bynfor web application and log in. 2. Navigate to Profile → Listing → Create Listing → Service. 3. Scroll through the page and look for the Listing Format section.


## ❌ Actual Result
The Listing Format section is not visible on the Service Create Listing page.

## ✅ Expected Result
The Listing Format section should be present, allowing users to select the appropriate listing format for their service.
