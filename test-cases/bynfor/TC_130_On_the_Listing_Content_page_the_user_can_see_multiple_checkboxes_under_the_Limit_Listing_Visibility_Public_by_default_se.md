## 🐞 Description
On the Listing Content page, the user can see multiple checkboxes under the “Limit Listing Visibility (Public by default)” section. However, the system only allows selecting one checkbox at a time — when another checkbox is checked, the previously selected one gets unchecked automatically.

## 🔁 Steps to Reproduce
1. Login to the website.  2. Go to SELLER Center from sidebar. 3. Click on List an Item.  4. Select any categotry under Create a simple listing.   5. Try to check all the boxes under Limit Listing Visibility (Public by default).


## ❌ Actual Result
Only one checkbox remains selected at a time; selecting a new one unchecks the previous.

## ✅ Expected Result
User should be able to check multiple options simultaneously if multiple visibility limitations are allowed.
