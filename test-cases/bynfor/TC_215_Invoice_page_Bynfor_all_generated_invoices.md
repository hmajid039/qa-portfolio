## 🐞 Description
On the Invoice page in Bynfor, all generated invoices are showing the same invoice number across multiple listings. Each listing should generate a unique invoice number for accurate transaction tracking and record-keeping. This issue can cause confusion in payment history, duplicate records, and accounting mismatches.

## 🔁 Steps to Reproduce
1. Log in to the Bynfor platform. 2. Create multiple listings and complete payment for each one. 3. Navigate to the Invoice section and open invoices for each listing. 4. Observe the invoice numbers displayed.


## ❌ Actual Result
All invoices show the same invoice number, regardless of the listing or payment.

## ✅ Expected Result
Each listing or transaction should generate a unique invoice number to maintain accurate billing and payment records.
